## Against the predictions
- **G1 WIN, as predicted.** No attacker value entered without the registry, as in the model-free test RF-1.
- **G2 not shown, as predicted** (more likely than not): with no registry a value needs three established voices, so the learner is slower; it named 88–89% of current holders, against NAIVE's 96–100% and 100% with the registry.
- **G3 and G6 NON-INFERIOR, and G5 WIN, as predicted.**
- **G4 was predicted WIN and is not shown.** Without the registry the learner answered dated questions at naive fine-tuning's level (48.6% and 46.2%, against 48.6% and 47.2%), 19.10 points below the learner with the registry. A likely reason, not tested here: the dates of earlier holders now come from the steps at which the memory settled each value, which lag the true dates because a value needs claims in two steps.

## What this result supports
- **Resistance to lies does not rest on the registry.** With no registry at all the learner answered no attacker value in either world, 8.70 points fewer than naive fine-tuning, and its memory never held an attacker value for any of the 184 attacked offices.
- **What the registry buys is speed and dates:** with it, the learner names 11.58 points more current holders and answers 19.10 points more dated questions.
- Benchmarks, never-streamed offices and offices learned early are unchanged without the registry.
