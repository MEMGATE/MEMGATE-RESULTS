## Changes after the spec, made on dev data before this freeze

| Change | Why |
| --- | --- |
| **Change dates.** For 157 facts whose date had defaulted to the newest release, the date is now the upload date of the first release without the old usage. It was found by installing the releases in between. | With the old dates, 64% of the dev world's changes fell in its last session, where no learner could learn them. Now 22% do. 124 dates moved earlier, by a median of 263 days. All 20 sampled exact dates agreed. |
| **Scorer forms.** Forms now respect word boundaries, ignore code comments, never count the library's own name or generic words, and add module.attribute forms from the verified paths. | Four frontier models labelled 140 dev answers blind, and the old scorer agreed with them on 95.7%. On a fresh sample of 160 answers it was not tuned on, the new scorer agrees on 96.2%. |

The dev run on the old dates is kept as `runs/cd1-dev-20261019-pre-fix-dates`. The current dev run uses the corrected dates.
