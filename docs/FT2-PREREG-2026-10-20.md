## Deviation: frozen before the dev run finished

**Why.** GPT-4.1 training jobs waited up to 4.5 hours for GPUs before starting. At that pace the dev run's last two blocks, then the main run's four, would have taken until 22 October.

**What was frozen early.** The hypotheses and the code. The code had run end to end through the dev run's first two blocks, including:
- a rollback;
- deployment, probing and deletion of every model.

FT-1's runner, whose training loop FT-2 copies, completed all four blocks in three worlds.

**What the late blocks can still do.** The dev run continues. Its later blocks inform nothing here, except a documented bug, which would be reported with its effect.
