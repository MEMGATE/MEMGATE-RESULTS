## 1. Question
The field summary lists "durable against temporary" among the problems specific to language models. A hybrid system keeps fast, reversible changes in memory and moves durable knowledge into the weights. It needs a rule for what to move. CN-1 compares rules for choosing which verified values to train into the weights.
- **Fine-tuning on the latest updates** moves the newest changes.
- **The layer's freshness estimate** can instead pick the values most likely to keep holding. FR-2 found it calibrated.
- **A value trained into the weights that stops holding** is a reversal. The weights then contradict memory, answer wrongly whenever memory misses, and need a rollback.

## 2. Design
**Offices and worlds.** RC-1's: every office in the 18 October 2026 Wikidata snapshot with a single holder on 1 January 2020, cut into worlds of about 240 offices. The main half has 20 worlds.

**Memory and weights.**
- Memory holds each office's verified holder.
- Every six months, on 1 July 2020, 1 January 2021, … and 1 July 2023 (seven consolidations), a policy chooses which offices' verified values to train into the weights.
- Only offices whose current value is not already in the weights are candidates. Each consolidation trains 10% of the world's offices (25% is descriptive).
- A trained value stays in the weights until its office is trained again.

**Policies:**
- **NEWEST:** the most recently started tenures first, as fine-tuning on the latest updates does.
- **FR2:** the values most likely to still hold six months later first, by `memgate.fresh.Freshness` fitted only on checks before 2020 (RC-1's fit).
- **RANDOM:** in random order.
- **Descriptive:**
  - LONGEST, the longest-held values first;
  - ALL, every candidate each time;
  - ORACLE, the values that really hold to the next consolidation (a bound).

**Measures,** monthly from 1 July 2020 to 1 December 2023, per world:
- **reversals per value trained:** the share of trained values that stopped holding before the next consolidation (within six months);
- **stale in weights:** the share of offices whose weights hold a value that no longer holds;
- **right in weights:** the share whose weights hold the current holder (what the weights answer if memory misses).

## 3. Hypotheses
Main half, 20 worlds. Each test is a 95% t interval over worlds (19 df) of the per-world difference, in percentage points.

| Test | Measure, volume 10% | Rule |
| --- | --- | --- |
| **H1 (primary)** | reversals per value trained, FR2 − NEWEST | **WIN** if the interval lies wholly below −1.0 pp |
| **H2** | stale in weights, FR2 − RANDOM | **WIN** if the interval lies wholly below −0.2 pp |
| **H3** | right in weights, FR2 − NEWEST | **NON-INFERIOR** if the lower bound is above −1.0 pp |

## 5. What CN-1 cannot show
- **It is model-free.** It counts what each rule would put into the weights, not what a model trained on it answers. RP-3, CH-1 and FT-1/FT-2 measure models.
- **One kind of fact (office holders), with a six-month cycle.** Other facts change at other rates.
- **Training is counted per value, not in GPU time.** ALL trains about 1.7 times as many values as a 10% policy, because after the first consolidation it trains only the changes.
