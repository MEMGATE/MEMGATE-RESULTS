# GI-1 preregistration: do lessons learned from a model's own mistakes hurt, or help, the answers they were not written for?

**Status:** frozen 21 October 2026, about 19:45 IST, before any main question was asked. Spec and preregistration in one document.
**Dev run:** `runs/gi1-dev-20261021` (RP-1's 50 dev offices, three models, 1,350 questions).

The hash covers `cl/gi1.py`, ML-M's lesson code (`cl/mlm.py`), RP-4 and RP-1's code, `shastra/llm.py`, RP-4's dev answers (where the lessons come from) and the Wikidata files.

## 1. Question
The field summary names a known failure: an edit placed in every prompt, a "global prompt edit", damages tasks it was not written for.

ML-M's lessons are such an edit. The system writes them from a model's own checked mistakes about a coach who moved clubs. ML-M measured them where they apply. GI-1 measures them on questions they were not written for.

**Built to find damage, dev found the opposite.** The lessons raised right answers on unrelated questions. The hypotheses below test that direction on the main offices, which have not been asked.

## 2. Design
**Questions.** RP-1's offices, each with RP-1's verified memory (one sentence naming the current holder). Three questions per office:
- **DIRECT:** who holds the post; right means naming the current holder;
- **STILL:** does the previous holder still hold it; right means "no";
- **STILLNOW:** does the current holder still hold it; right means "yes".

**Conditions:**
- **SCOPED:** no lessons. An edit kept to its own cases does not appear in these prompts, so the prompt is the memory alone.
- **GLOBAL-1:** each model's own lessons in ML-M's first wording, in every prompt.
- **GLOBAL-2:** the same, in ML-M's second wording.

**Models:** gpt-4.1-base (temperature 0), gpt-6.1-sol and gpt-6-astra, with 5, 5 and 2 lessons.

**Offices:** dev used RP-1's 50 dev offices. **Main uses RP-1's 300 main offices:** 2,700 questions per model, 8,100 in all.

## 3. Hypotheses
**The statistic:** for each office, average over models and the three question kinds the difference between two conditions' 0/1 outcomes. The estimate is the mean over offices, with a 95% bootstrap interval over offices (10,000 resamples, seed 12345).

| Test | Comparison | Rule |
| --- | --- | --- |
| **H1 (primary)** | right answers, GLOBAL-2 − SCOPED | **WIN** if the interval lies wholly above +1 pp; NO WIN if its upper bound is below +1 pp; otherwise UNDETERMINED |
| H2 | right answers, GLOBAL-1 − SCOPED | same rule |

## 4. Predictions (dev)

| Test | Dev estimate, pp [95% interval] | Dev verdict |
| --- | --- | --- |
| H1 | +9.33 [+6.22, +13.33] | WIN |
| H2 | +6.22 [+3.11, +10.22] | WIN |

**Where the gain comes from.** Mostly STILLNOW. Without lessons, gpt-4.1-base said "no" to "is the current holder still in post?" for 54% of offices, though its memory named that person. The lessons are about trusting what the record shows, and they made its answers agree with its memory.

## 5. Limits
- **One edit, one kind of fact,** and short prompts. Other global edits, worded otherwise, can do harm, as ML-M's first wording did where it applied: there it made models answer "unknown" to almost everything.
- **SCOPED is the memory alone by construction.** The test compares lessons against no lessons on questions outside their case.
- **The gain is close to the ceiling** for the two stronger models.
