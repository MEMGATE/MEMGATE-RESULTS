## What this means
- **Real editors, real mistakes, and the gate holds.**
  - Believing every edit would have put 149 wrong values into a learning system. The gate let in 2, both past holders of the office, not inventions.
  - It dismissed three editors, each with wrong claims, and **no honest editor**. RV-1 failed on exactly this point: there the gate dismissed 69 editors who were never reverted, because edits were misread as claims.
  - Accuracy in the last month is the same as believing everyone (−0.02 pp).
- **Most real mistakes are never caught by the community.** Of the 149 wrong values, Wikidata reverted 5. A system that waits for reverts would have kept 144 of them.
- **On this stream, using the registry alone is as good.** Registry-only learned no wrong value and has the same accuracy. That is expected here:
  - the registry is Wikidata's own settled timeline, so it is right by construction;
  - it reports 5% of offices unasked every month;
  - real editors rarely build the repeated, checked record that testimony needs.
  
  The gate's added coverage over registry-only is 0.3 pp. What RV-2 shows is that the gate does not punish real, honest editors, and keeps their mistakes out. It does not show an advantage over a perfect registry. AU-2 tested the gate with a registry that is wrong 5–10% of the time.

## What this does not show
- **The registry is Wikidata's settled timeline:** the hindsight consensus of the same editors, standing in for an official source.
- **Some edits are not in the stream:** qualifier-only API edits, bulk edits and reverts, because they never name an office property in their summary. Each listed edit is still read against its own parent revision, so their effects are seen.
- **Descriptive only:** one historical stream, so there are no confidence intervals. The predictions were descriptive by design.

## Note added on 28 October 2026, 17:40 IST: claims that name a recorded holder under another Wikidata item
This was found while building RW-1 on the same stream; it is a post-hoc note, and the preregistered result above is unchanged.
- RV-2 counts a claim as naming "someone never recorded as holder" by Wikidata item. Of the 37 such claims, 5 name a value that Wikidata does record for the office, under another item, by label or alias.
- Four name the holder of the time. They are the same person under a second item: the mayors of Piatra Neamț and Ploiești, the coach of SC Austria Lustenau, and the CEO of ASML.
- One names a vacancy ("job vacancy") while the office's record holds a vacancy item for another period.
- Counted by item, as preregistered, all five are wrong: 149 wrong values, 2 let in by the gate (1.3%).
- Counted by name, the four are right: 145 wrong values, with the same 2 let in (1.4%). The gate let in none of the five.
- Outward text gives the preregistered count, says it is counted by Wikidata item, and gives the by-name count beside it.
- RW-1 scores answers by name. From 28 October its real-stream world (`cl/real_world.py`, `same_name`) does not count such claims as wrong values.
