**Written:** 21 October 2026, 18:35 IST. A plan, not a result.

**The founder's rule:** once the GPU is there, keep it busy with tests back to back and do not release it.

## Ready now
**`cl/open_rp3.py`** runs RP-3 on an open model with LoRA:
- RP-3's arms, training rows, questions and scorer, unchanged. The rows are DIRECT, FOLLOW and MORE; FROZEN is the untouched model.
- One adapter per arm, trained from the untouched weights.
- Greedy answers, written in RP-3's format, so `rp3.report` scores them.
- `--4bit` loads 70B-class models for QLoRA on one 80 GB GPU.

**Checked:** a smoke run on this machine's CPU with Qwen2.5-0.5B-Instruct (`--smoke`: 8 rows, 6 questions) trained all three adapters and wrote every answer, in 75 seconds. The 4-bit path needs CUDA and has not been run.

## Setting up the machine
1. **Create the VM** with an NVIDIA-ready image, for example `microsoft-dsvm:ubuntu-hpc:2204:latest`, size `Standard_NC24ads_A100_v4`, in East US 2, with a 512 GB disk.
2. **Install:** `torch==2.5.1` (CUDA 12.4 build), `transformers==4.46.3`, `peft==0.13.2`, `accelerate==1.1.1` and `bitsandbytes`.
3. **Copy `claude_lab`** to the VM with `scp`: its code and `data/wikidata-changes`. No keys are needed: these runs call no service.
4. **Run the queue detached.** Commit each run's `manifest.json`, `log.jsonl` and `answers.jsonl` back to the branch.
