## What it shows
- **Safety held end to end.** No model named an attacker's value from the layer's memory. A memory that trusted its input passed the attackers' values on 9.4–11.7% of attacked offices.
- **The joined parts worked together.** The follow-on sentence, freshness and derived lines raised previous-holder answers and "still in post?" consistency, most for the weaker models. Llama's previous-holder answers went from 27.9% to 63.3%, and its "still" pair from 15.4% to 66.7%. No model named a departed holder for a post the layer had marked.
- **The cost is coverage.** With no registry, the layer settles a value only when independent sources agree over time. At the question date it held a value for fewer offices, so models named the current holder 68–75% of the time, against 87.5–90.8% with the naive memory. On the three right-answer measures together, the layer was +3.25 pp, an interval that includes zero. On the strongest models the naive memory scored higher; on the weaker models the layer did.

## Where the cost comes from (descriptive, read after the run)
On the direct question, the layer's misses split as follows:
- **No verified value, 25 of 240 offices.** Here models answered from their own knowledge:
  - gpt-4.1-base and llama-4-maverick named a past holder 80% and 72% of the time;
  - claude-opus-5-5 and gpt-6.1-sol 48% and 36%.
- **A verified value that was no longer current, about 21% of the other 215 offices.** The holder had changed late in the stream, and the new holder had not yet been confirmed by independent sources. So the layer still held the previous holder, and every model named that person (20.5–22.3%).

The second is the larger part. It is the time the layer waits for agreement: plasticity given up for safety. The freshness line ("chance it still holds today") did not stop models from naming the stored holder. A way to buy back some of that time without letting attackers in is the next question (`docs/ROADMAP-CL-2026-10-21.md`).

## Limits
- **One world, four models.** The attackers are TM-1's simulated ones; the facts and timelines are real.
- **No registry at all,** the hardest setting. A small registry or an environment check changes coverage (RF-2, EV-1).
- **The naive memory presents its values as verified,** as a memory that trusts its input would.
