## 1. Question
A continual learner should know which of its stored facts may have gone out of date. For a value checked on some day, can the memory give a calibrated probability that it still holds d days later?

## 2. Design
**Cases.** In the Wikidata snapshot, an office checked on day t0 either has the same holder d days later or it does not.
- d is 30, 90, 180, 365, 730 or 1,095 days.
- Each office gets four check days, drawn with a seed.

**Fit.** Checks between 2016 and 2019, over every office.

**Test.** Checks from 2020 to 2022 whose look-again day falls before 1 January 2024. The snapshot chose its offices by what happened after March 2024, so later look-again days would be biased toward change.
- Offices are split in halves by TM-1's hash.
- Dev scored the dev half (seed `FR2-DEV`).
- **Main scores the main half (seed `FR2-MAIN`).**

**Predictors:**
- **BASE:** the share still true at each horizon, over all fitted checks.
- **TABLE:** the share still true among fitted checks of the same kind of post, the same holder-tenure band (under 1 year, 1–4, over 4) and the same horizon. It is smoothed toward BASE with weight 5.

**Scores:**
- the Brier skill of TABLE over BASE, 1 − Brier(TABLE) / Brier(BASE);
- TABLE's expected calibration error over ten bins.

Both have 95% intervals from 2,000 bootstrap resamples of offices, seed 12345.

## 3. Hypotheses
| Test | Rule |
| --- | --- |
| **H1 (primary):** Brier skill of TABLE over BASE | **WIN** if the interval lies wholly above 0.10; **NO WIN** if wholly below; otherwise UNDETERMINED |
| H2: expected calibration error of TABLE | **WIN** if the interval lies wholly below 0.02; **NO WIN** if wholly above; otherwise UNDETERMINED |

## 4. Predictions (dev half)
- **Skill:** 0.154 [0.134, 0.174].
- **Calibration error:** 0.0136 [0.0111, 0.0160].
- **Data:** 104,294 cases on 5,558 offices.
- **Verdicts:** both WIN.
- **Where it errs:** the middle bins are overconfident, for example 0.40 predicted where 0.31 held. They hold few cases.

## 5. Limits
- **Domain:** office holders only. The tenure bands and horizons are coarse.
- **What it measures:** calibration only. Using the probabilities is not tested here: answering with "as of" and a confidence, or checking the least likely values first.
- **Selection:** the snapshot's selection of offices is handled by the look-again cutoff, not removed.
