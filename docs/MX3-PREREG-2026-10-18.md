# MX-3 preregistration: frozen before the main run

18 October 2026. This freezes MX-3 as defined in the [spec](MX3-SPEC-2026-10-18.md), including its clarified definition of an autonomous answer: the system neither asked nor audited.

- Code SHA-256: `3bd3ad49d7899cba6cede8c67aaec8441d713fb599f295cac2abc17037e88ebf`. It is the same code as the dev run (commit `6928a31b`).
- Held-out data: synthetic worlds of all five families at the new seeds 37000–37019.

## Rules fixed in the code

**Asking.** Under doubt, by PV-1's rule.

**Answering alone.** Only when all three members agree and the lesson member does not doubt.

**Audits.** 5% of those cases, drawn by `random.Random(seed + 4242)`.

**The health check and reset.**
- The health check is PK-1's, applied to the assembly's errors on every observed case (asked or audited).
- On vikṛti, all three members are rebuilt from the latest 30 observed cases.

**Scoring.** A run in which either arm answered nothing alone counts 0 for that comparison.

**INVALID conditions:**
- any non-determinism in the repeats;
- a failed run;
- GRAND+AUDIT never resetting on DRIFT.

## Dev run (exposed data)

The output is in [`runs/mx3-dev-20261018-a`](../runs/mx3-dev-20261018-a/SUMMARY.md). It covers the synthetic dev seeds and the nine exposed real streams. There were 315 runs, all 14 repeats were identical, and nothing failed.

| Comparison (autonomous accuracy) | pp, 95% CI | Verdict |
| --- | --- | --- |
| H1: GRAND+AUDIT − GRAND, DRIFT | +9.85 [+7.94, +11.74] | WIN |
| H2: GRAND+AUDIT − GRAND+AUDIT-NORESET, DRIFT | +5.90 [+5.20, +6.65] | WIN |
| H3: GRAND+AUDIT − GRAND, stable families | +0.57 [+0.13, +1.08] | UNDETERMINED |
| GRAND+AUDIT − GRAND, the nine exposed real streams | +7.64 [+5.55, +9.47] | descriptive |

**Findings.**
- **The blind spot is real, and on real streams it can be severe.**
  - On the ldpa activity stream, GRAND answered 94.6% of cases alone, with only 26.1% right.
  - Its members agreed on the old activity and never asked.
  - With 5% audits and the health check, it answered 64.0% alone, with 74.9% right.
- **The reset matters beyond the audit labels** on DRIFT (+5.90 pp).
- **On stable worlds,** the audits cost about 5% more labels. Their answers were no worse, slightly better (+0.57).

No bug was found, and nothing changed after the dev run.
