# The demo labs question themselves: plan (Part B item 15, 28 October 2026)

## What a reviewer sees
- A token link opens one page with two columns. Both columns are the same open model.
  - The left column is the model untouched.
  - The right column is the model after its monthly updates on Wikidata's real 2024–2026 edit stream: RW-1's main run, `--save-adapter`.
- The reviewer types any question. Both answers come back with greedy decoding, nothing looked up at answer time.
- The right column answers from its trained weights when the scope rule routes the question there. This is exactly as the tests score it.
- A few fixed examples are offered. They are drawn from the run's own last evaluation:
  - current holders the learner answers and the untouched model does not;
  - offices whose real stream carried a value Wikidata never records.

## What never leaves
- No code, method, payload or adapter.
- The server keeps no log of questions.
- Each lab gets its own token. A token can be revoked by restarting the server with a new one.

## Where it runs for the review window
- **Machine: the lab's A100 VM** (`memgate-a100-scus`), after the package's GPU runs end (about 1–2 November).
  - Same GPU model as the tests; the 7B in 16 bits, as tested.
  - A T4 cannot hold the 7B in 16 bits.
- **Address:** HTTPS through a reverse proxy with an automatic certificate on the VM's Azure DNS name.
  - The label is neutral and random; it does not name the lab or the method.
  - Port 443 is opened to the internet only for the review window; SSH stays limited to the lab machine.
- **Process:**
  - `DEMO_TOKEN=<per lab> python cl/demo_server.py --model Qwen/Qwen2.5-7B-Instruct --revision a09a35458c70… --adapter bundle/adapter --scope bundle/scope.json --port 8080`, behind the proxy;
  - a service unit restarts it on failure.
- **Cost:** about 3.7 US dollars an hour while it runs. The founder: Azure cost is not a concern.
