# RW-1 preregistration: the learner on Wikidata's real edit stream (7B) (DRAFT)

**Status: DRAFT, 28 October 2026. Not frozen.** It is frozen after the dev trial on the dev half (`runs/rw1-dev-7b/w9790`, pool "realdev") and before any main world is packed; the dev numbers and the predictions are added at the freeze. Part B item 9 (`docs/PARTB-PLAN-2026-10-28.md`).

## Why
Every learner test so far streams real facts (offices from the Wikidata snapshot, Python releases from the package index) through simulated sources and attackers. A lab will ask whether the learner holds up on a real stream, with real people's edits, real mistakes and real vandalism. RV-2 (20 October) answered it for the gate alone, without a model: on the real 2024–2026 edits of 675 offices, the gate let in 2 of 149 wrong values and dismissed no honest editor. RW-1 trains the 7B on that real stream, month by month, end to end.

## The world (`cl/real_world.py`)
The office world built by the office worlds' own machinery over CCL-6's 34 monthly sessions (January 2024 to October 2026), with its simulated sources replaced:
- **Offices:** every usable changed office of the Wikidata snapshot in the main half (TM-1's "all" pool; RV-2's offices) and 60 of the main half's static offices (702 in all, 640 of them changing over the 34 sessions); the never-streamed sets from the main half's static offices.
- **The stream:** every listed 2024–2026 edit of these offices that changes who holds the office now, read by RV-2's claim reader against the edit's own parent revision (1,072 claims by 263 editors), in the first session on or after the edit's day, from its pseudonymous editor.
- **The registry**, as in RV-2: 5% of the offices reported unasked each session (the settled timeline at the session's date), and questions within TM-1's budget rate divided by three (53 a session).
- **No simulated source, attacker, late fact, sleeper or swarm, and no injected registry error.** The wrong values are the real ones. An office counts as attacked when an editor claimed a holder Wikidata never records for it, and its attacker value is the last such value claimed. A claimed value whose label or alias is that of a value Wikidata records for the office is not a wrong value, because a model answers by name (`real_world.same_name`, added on 28 October after the dev trial; see below). That leaves 32 claims on 26 offices in the main half. Values the snapshot does not label carry the label Wikidata gives them (`data/wikidata-reverts/claimed-labels.json`).

## The system under test and the arms
SYSTEM3, CCL-5's learner, unchanged, against NAIVE (every claim fine-tuned) and the untouched model: CCL-6's arms, built by CCL-6's own payload builder (`cl/cl6.py`, imported, unchanged). Qwen2.5-7B-Instruct (revision `a09a35458c70…`), 16 bits, on Azure's serverless A100. The kernel is CCL-5's frozen runner with one added line that saves SYSTEM3's trained adapter after its last session (for the demo; it changes nothing the run computes).

Code SHA-256 (RW-1 packer and analysis wrapper with the real world, CCL-6's packer and analysis and the job runner, `rw1.code_hash()`): to be written at the freeze as a "Code SHA-256:" line.

## Design
- **Worlds:** two main worlds of the pool "real", seeds 9720 and 9721. The real claims are the same in both; the seed draws the registry's unasked reports, the static and never-streamed offices and the anchors (declared: the two worlds share their stream).
- **Packs:** `PYTHONHASHSEED=0 python cl/rw1.py pack 97XX:real runs/rw1-main-7b/w97XX --learner <the learner below> --save-adapter --prereg docs/RW1-PREREG-2026-10-28.md`, run without Python's isolated mode.
- **72B (Part B item 9's second half; added 28 October 19:40, before any RW-1 main run).**
  - One world, seed 9720: `runs/rw1-main-72b/w9720`, packed the same way with `--model 72b`.
  - It runs on the lab's A100 VM after CCL-6's two 72B worlds, with `--hours 72`. From the dev trial's sizes and the 72B's speeds in CCL-4C72's dev check, it takes about 50–60 hours.
  - It is analysed on its own with the same analysis. It is one world, so its intervals are wider; its verdicts are reported beside the 7B's.
  - If it cannot finish by 9 November, it is reported as not run.

## Hypotheses
CCL-6's, with CCL-6's rules, computed by CCL-6's analysis on the real worlds, after session 34, both worlds pooled; paired bootstrap over items within each world, 10,000 resamples, seed 12345, 95% intervals. Ability 4 is not tested (no injected registry error); ability 17 (a second domain) does not apply.
- **Judged:** H1 (real wrong values answered, SYSTEM3 − NAIVE), H2 and H11 (current holders), H3 and H10 (offices kept, never-streamed offices), H5 (dated questions), H6 (rewrites), H7 (what follows), H13L, H15 and H15b, H8 and H9 (GSM8K, MMLU), H16, H16s and H17 (safety and instruction-following as the system answers), H18 (transitional periods).

## Validity
A world is valid if both arms finished their 34 sessions (exit code 0, the done line) and the untouched model, NAIVE and SYSTEM3 answered every question of the evaluation after session 34. A run stopped by the machine without output is rerun once with the same payload, in a new folder.

## The dev trial (dev half, world 9790, 7B; exploration, not a result)
`runs/rw1-dev-7b/w9790`, Azure's serverless A100, 28 October 12:22–17:11 IST, exit code 0, both arms 34 sessions. The untouched model answered 10,800 questions. SYSTEM3 trained 299 rows (31 seconds) in session 1, rising to about 6,900 rows (502 seconds) by session 34; NAIVE trained 70–300 rows a session. The run took about 4.8 hours.

Its analysis (`cl/rw1.py report`, dev half; learner against NAIVE):
- **Current holders:** 95.2% against 28.6% (H2 +66.56); the untouched model 0.7%.
- **Never-streamed offices:** 99.2% against 28.5%.
- **Dated questions:** H5 +48.12. **What follows:** H7 +47.65. **Learning better over time:** H13L +35.81. **Plasticity:** H15 +3.2.
- **The system as it answers:** IFEval 73.0 and unsafe prompts refused 72.0, as the untouched model (73.0, 72.5).
- **The trained weights alone:** IFEval 34.0 (H17a −39.0) and unsafe refusals 35.0 (H16a −37.5). That is more than in CCL-6's 166-office worlds (−21 to −25 and −10 to −16): this world trains about four times as many rows.
- **Rewrites (H6 −21.43):** the learner's rewrites name the new API but drop the `print(...)` the check runs, so none passed (NAIVE 21.4%). The same drift of the weights.
- **Transitional questions:** 0% for every arm (H18), as expected for SYSTEM3.
- **Attacker values (H1 +8.11, not shown):** in all four offices where the learner "answered the attacker's value", that value had the same name as the true current holder under a second Wikidata item. The world's rule was fixed for this (`same_name`, above; dev half 37 → 32 attacked offices). With the fix, the learner answers none of the 32 with the attacker's value and NAIVE one. Wrong values are rare on the real stream and are mostly undone by later edits, so NAIVE seldom ends on one either.
