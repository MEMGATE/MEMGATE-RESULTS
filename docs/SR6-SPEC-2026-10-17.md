# SR-6: akhyāti (non-discrimination) and pratyāhāra (withdrawal), plus the best-so-far mix

**Status:** design, written on 17 October 2026 before any SR-6 code and before the SR-5 and J-1 main results were read. No model calls are made.

## 1. Sources

Both ideas were studied earlier by Ember as mechanism-only engineering bars inside the Pramana agent:

- [`KHYATI-STUDY-REPORT-2026-10-12`](../../docs/KHYATI-STUDY-REPORT-2026-10-12.md): SURVIVE, then KILL in phase 2;
- [`PRATYAHARA-P1-REPORT-2026-10-10`](../../docs/PRATYAHARA-P1-REPORT-2026-10-10.md): P1 SURVIVE.

Neither was ever compared with an ordinary learner. The mappings below are mine.

- **Akhyāti.** This is Prābhākara Mīmāṃsā's theory of error. Nothing false is apprehended; error is a failure to discriminate two cognitions (*vivekāgraha*).
  - The learning analogue: a counterexample whose features are *identical* to a case the lesson already explained gives no ground for discrimination. No literal can separate the two.
  - So the lesson should not be revised on account of it.
- **Pratyāhāra.** Yoga Sūtra 2.54: the senses withdraw from their objects and follow the mind's own nature.
  - The learning analogue: when no lesson decides, the fallback attends only to the features that the learner's own lessons use. It withdraws from the rest.

## 2. Mechanisms

Both mechanisms are added to the ordinary rule learner R-ORD.

**AKHYATI.**

- **What it changes:** a validated lesson meets a counterexample whose row is identical to the row of one of its supporting cases. Then the lesson is not revised. The case is recorded as indiscernible.
- **Retirement:** once the indiscernible counterexamples are at least as many as the supporting cases, the lesson is discarded, because it discriminates nothing.
- **Everything else is unchanged:** a counterexample that differs from every supporting case in some feature is revised by ordinary FOIL.

**PRATYAHARA.**

- **What it changes:** the 1-NN fallback computes its Hamming distance only over the features that appear in the conditions of at least one active validated lesson.
- **When it does not apply:** when there is no such lesson, all features are used.
- **Ties:** go to the most recent case, as before.

## 3. Arms

| Arm | Content |
| --- | --- |
| EXT-DT, EXT-NB, EXT-1NN | non-lesson baselines |
| R-ORD | baseline |
| R-ORD+AKHYATI | AKHYATI only |
| R-ORD+PRATYAHARA | PRATYAHARA only |
| MIX-SR6 | AKHYATI + PRATYAHARA |
| MIX-BEST | R-ORD + AKHYATI + PRATYAHARA + every earlier mechanism selected by the rule below |

**MIX-BEST rule, fixed now.** A mechanism is included if its own single-mechanism comparison against R-ORD had a 95% CI lower bound above 0 on held-out real data in at least one main run up to and including SR-5. The list is computed from the frozen main-run results and written into this spec before any SR-6 code. As of SR-4 only ANU qualifies: SR-3 +0.34 and H-1 +0.45, both significant.

## 4. Data

**Held-out:** nine UCI datasets, new to the lab. Each runs in 10 orders (seeds 16000–16009) and is cut to 1,000 cases. Numeric columns are binned by the H-1 rule.

The pool mixes wide data, where withdrawal can matter, with narrow, duplicate-rich data, where indiscernible counterexamples are common: Haberman, maternal health and rice.

**Synthetic:** the five SR families with seeds 16000–16019.

**Dev:** exposed data only. That is the 38 earlier datasets, plus the SR-5/J-1 pool and streams once their main runs have finished, and earlier synthetic seeds.

## 5. Hypotheses and decision rules

The decision rules are as in SR-1 to SR-5.

| Hypothesis | Comparison |
| --- | --- |
| **H1 (primary)** | MIX-BEST − R-ORD on the nine held-out datasets |
| H2 | R-ORD+AKHYATI − R-ORD |
| H3 | R-ORD+PRATYAHARA − R-ORD |
| H4 | MIX-SR6 − R-ORD |
| Descriptive | MIX-BEST − EXT-NB and − EXT-DT |

The run is INVALID if, on held-out data, AKHYATI never keeps a lesson or PRATYAHARA never withdraws a feature in its own arm.
