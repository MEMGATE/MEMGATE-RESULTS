## Rules fixed in the code

**SL-1's rules, unchanged.**
- R-ORD.
- R-ORD+LOCUS: the locus is an ordinary feature.
- SAME-LOCUS: a lesson decides only if one of its supporting cases comes from the case's locus, and the fallback is the nearest stored case of the same locus.
- RANDOM-LOCUS: as SAME-LOCUS over random groups of the same sizes (`random.Random(seed + 666)`).

**INVALID conditions:**
- non-determinism;
- a crashed run.

## Runs before the freeze

There were none on these data. The loaders were checked by shape and label counts.

**One loading error was caught by that check and fixed before the freeze.** The Seoul file codes missing values as `NaN`. The first loader read them as numbers, and that broke the median split (6,846 / 904). With `NaN` read as missing, the split is 3,924 / 3,799.
