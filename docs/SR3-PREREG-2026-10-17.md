### Why BAD scores exactly 0.00

BAD is equivalent to R-ORD by construction, not because of a bug:

- In a precision-1 learner, no active lesson can contradict a stored case.
- When no lesson matches, 1-NN already returns the most recent identical case.

Its counter (`pratyaksa_decisions`) does fire, so H4 is not INVALID. It is expected to be NO WIN.

No implementation bug was found.
