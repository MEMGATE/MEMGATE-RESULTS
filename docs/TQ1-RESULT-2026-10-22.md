## What it shows
- **A dated memory line answers both the present and the past.** The line gives the current value, the date it changed and the value before (the layer's line). With it, the models answered 86.0–100% of questions about a date before the change and 93.7–100% after it.
- **A memory that keeps only the current value misleads about the past.** Asked about a date before the change, gpt-4.1-base named the current holder for 97.0% and llama-4-maverick for 94.3%. Without any memory they had answered 45.3% and 40.3% right.
  - The cost averaged −17.78 points over the six models.
  - Overwriting a value, in memory or in the weights, loses the time it held.
- **Keeping the date cost nothing on present questions overall** (H3, +1.44). One model, gpt-4.1-base, named the previous holder for 6.3% of AFTER questions with the dated line, against 0.3% with the current value only. A wording exploration on dev found no better line (LOG, 22 October).

## Limits
- **Office holders, one change per office:** the latest change and the holder just before it.
- **Dates inside the record's tenures.**
- **The memory route only** in the preregistered test. The weights route was asked afterwards, descriptively (below).

- **The models:** GPT-4.1 untouched (gpt-4.1-base), and RP-3's three main models fine-tuned on these offices' new holders: DIRECT, FOLLOW and MORE, through Azure's hosted fine-tuning.

- **Fine-tuning on the new value overwrote the time it changed.** Fine-tuned on the new holders (DIRECT and MORE), GPT-4.1 named the new holder for 82.8% and 84.5% of questions about a date before the change. Untouched, it named the right holder for 50.7%: 45.86 points better than DIRECT (95% bootstrap interval 40.34 to 51.72, 290 offices).
- **Training also on whom the new holder replaced helped a little:** FOLLOW was right for 14.5% of past dates, 9.66 points above DIRECT [5.86, 13.79].
- **The memory route kept it** (above). With the dated line, gpt-4.1-base answered 99.7% of past-date questions on TQ-1's offices.
