## How to read this

**What the WIN shows.** When a domain's features really fall into the groups an ontology names, telling the learner those groups (as group-level features) helps a great deal. A grouping of the same shape that cuts across the true one does not help: it is no better than no grouping, and sometimes worse.

**Where the value lies.** It lies in the categories being right, not in having categories at all. That is the honest content of a "tattva ontology" claim for AI. The worlds were built with the Sāṃkhya-shaped grouping, so O-1 cannot show that Sāṃkhya's classification is right for any real domain.

**Next step.** The next test needs a domain whose groups were not chosen by the experimenter, for example a real dataset with an independent categorisation. It is listed in the coverage register.
