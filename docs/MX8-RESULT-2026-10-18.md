AR-1's network, with Multiple Features and MHEALTH, is the fourth setting. It failed only on the naval simulator (MX-6), where no single source could decide. On every setting where a sensor failed, the broken one was found almost always.

**Telling each spy the person helped little here.**
- With the plain network the person changed nothing (−0.04).
- Inside the supervisor it added +1.38, not significant.
- In SL-2 the locus mattered most where units differ in a stable baseline: Parkinson's patients, +24 pp. Eight healthy people performing the same 19 activities differ much less, and each spy sees too few cases per person to learn a person-specific rule.

**For a working system.** The core supervisor is robust across settings. Adding the site or camera identity is worth it only where sites differ in baseline. Test that per deployment.
