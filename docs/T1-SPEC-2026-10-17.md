# T-1: Sanatana cyclic time (pañcāṅga) vs linear time, generic cycles and Kālacakra-style recency layers

**Status:** design, written on 17 October 2026 before any T-1 code was run. No model calls.

## 1. Question

The pañcāṅga ("five limbs") gives every day several simultaneous cyclic coordinates. Two of its limbs are used here:

- **Vāra:** the weekday, 7.
- **Tithi:** the lunar day, 30 per synodic month of about 29.53 days, which also gives the pakṣa or half-month.

To these, T-1 adds two coordinates from the same calendar system:

- **Nakṣatra:** 27 per sidereal month of about 27.32 days.
- **Solar māsa:** 12 per year.

Yoga and karaṇa are not used. They need solar and lunar longitudes and add no new period.

**The T-1 question:** when outcomes recur on cycles, does representing time this way help a continual learner more than four alternatives?

- No time at all.
- Linear time.
- Generic multi-scale cycles of the kind ML uses, here dyadic phases.
- A Kālacakra-style recency-layer retrieval.

**Prior caveat.** If nature's cycles *are* lunar, weekly or solar, pañcāṅga features help almost by construction. T-1 therefore includes cycles at periods the pañcāṅga does not have (10 and 45 days). It also includes no cycle at all, and drift. This shows when the encoding helps and when it costs.

## 2. Worlds

Every world has one case per day for 730 days, from a random phase.

- **Static part.** There are 8 categorical static features with 2–4 values each. The base rule is `L1 if f_a = v0, else L0`.
- **Cycle part.** The label is the base rule XOR a cycle flag. The cycle flag depends on the family:

| Family | Cycle flag |
| --- | --- |
| WEEK | the weekday is in a random set of 2 |
| LUNAR | śukla pakṣa, the bright half |
| NAKSHATRA | the nakṣatra is in a random set of 9 |
| SEASON | the solar māsa is in 3 consecutive months |
| OFF10 | `t mod 10 < 5` (not a pañcāṅga period) |
| OFF45 | `t mod 45 < 20` (not a pañcāṅga period) |
| NONE | always false |
| DRIFT-T | no cycle; the base rule switches to `f_b = v0` at day 365 |

**Seeds:** dev 0–4 (exposed), main 9000–9019. That makes 8 families × 20 = 160 main worlds.

There is no real dataset with dated categorical cases in the corpus. This is a limit, stated in §5.

## 3. Arms

### Encodings

Each encoding is a set of features appended to the 8 static features.

| Encoding | Features added |
| --- | --- |
| `none` | nothing |
| `linear` | `lin = t // 30`, as a categorical value |
| `pancanga` | vāra, tithi, pakṣa, nakṣatra and māsa (5 features) |
| `generic` | `t mod 2`, `t mod 4`, `t mod 8`, `t mod 16` and `t mod 32` (5 features, the ordinary multi-scale comparator) |

### Learners

- **Learners × encodings:** R-ORD, EXT-DT and EXT-NB, each with each encoding (12 arms).
- **R-ORD:kala:** the `none` encoding plus Kālacakra-style layered recency retrieval for the fallback.
  - The cases are split into three layers: the last 30, the 31st to 180th most recent, and everything older.
  - The best match in the most recent layer is accepted if its distance is within 1 of the best match overall. Otherwise the next layer is tried.
  - This keeps the "inner = recent, search outward" order without the budget gates that made KC-EXP-1 INVALID.

## 4. Hypotheses and decision rules

The units are worlds. Strata are the families named in each hypothesis, and the SR-1 decision rules apply.

| Hypothesis | Comparison | Families |
| --- | --- | --- |
| **H1 (primary)** | R-ORD:pancanga − R-ORD:generic | WEEK, LUNAR, NAKSHATRA and SEASON. Do the śāstra's specific periods beat generic cycles where nature has those periods? |
| H2 | R-ORD:pancanga − R-ORD:none | all eight |
| H3 | R-ORD:pancanga − R-ORD:none | OFF10, OFF45 and NONE. This is the cost when the cycles do not match. |
| H4 | R-ORD:kala − R-ORD:none | all eight, and DRIFT-T separately |

The same comparisons for DT and NB are descriptive.

## 5. Predictions and limits

**Predictions:**

| Hypothesis | Prediction |
| --- | --- |
| H1 | WIN on the matching families. Generic dyadic phases cannot express 7-, 27.3- or 29.5-day cycles. |
| H2 | WIN, driven by the four matching families. |
| H3 | ≤ 0. The irrelevant features cost something. |
| H4 | Positive on DRIFT-T, ≈ 0 elsewhere. |

**Limits:**

- All worlds are synthetic.
- The matching families are built from the pañcāṅga's own cycles, so H1 shows representational fit, not that real phenomena follow those cycles.
