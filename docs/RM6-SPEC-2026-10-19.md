# RM-6: does a small model need the gate more? RM-1 with gpt-4.1-nano, on RM-1's own worlds

**Status:** design, written on 19 October 2026 before any RM-6 code.

## 1. Question

**What RM-1 found.** RM-1 put the gate in front of a frontier reasoning model's retrieval memory (`gpt-6.1-sol`). Reading every raw report, with source and session and a careful instruction, that model got close to the gate by the end:
- 99.8% truth and 1.2% poison after session 12;
- but 16.6% poison after session 4, and prompts nine times larger.

**What RM-6 asks.** Memory systems are often read by small, cheap models. The question is whether the gap between raw and gated memory widens when the reader is small, and whether, with the gate, a small model matches the frontier one.

## 2. Design

**Protocol: RM-1's, unchanged.**
- The world is SE-2's: a stealthy poisoner, two colluders, honest sources that lag, and a registry.
- The memories, the instruction, the questions, the evaluation points (after sessions 4, 8 and 12) and the scoring are RM-1's frozen code (`cl/rm1.py`, `cl/run_rm1.py`).
- RM-6 changes only the model (`cl/run_rm6.py`).

**Arms:**
- **NONE:** no memory.
- **LATEST:** the last report.
- **RAW:** every report, with its source and session, and RM-1's instruction.
- **GATED:** the gate's verified value.

**Model.** `gpt-4.1-nano` (`2025-04-14`), a small non-reasoning model. It is deployed on the same Foundry resource at GlobalStandard, and reached with the Entra token.

**Worlds:**
- **Dev:** SE-2 world 0, exposed.
- **Main:** RM-1's main worlds, seeds 5000–5007. The two models then read identical memories, and the comparison with `gpt-6.1-sol` is paired by world. Nothing in RM-6 is chosen on those worlds.

## 3. Hypotheses

The first two are for `gpt-4.1-nano` after session 12. The last two compare it with RM-1's `gpt-6.1-sol` on the same worlds. The bootstrap is over 8 worlds, with 10,000 resamples and seed 12345.

| Hypothesis | Comparison | Rule |
| --- | --- | --- |
| **H1** | Poison: GATED − RAW (nano) | WIN if ≤ −1 pp with the CI's upper bound below 0 |
| **H2** | Truth: GATED − RAW (nano) | WIN if ≥ +1 pp with the CI's lower bound above 0 |
| **H3** | Truth with the gate: nano − sol | NON-INFERIOR if the CI's lower bound is above −2 pp |
| H4 | Truth with raw memory: nano − sol, after sessions 4 and 12 | descriptive |

**INVALID if:**
- more than 1% of calls fail after retries;
- GATED truth is below 90% (the model cannot read a one-line memory).

## 4. Predictions

- **H1 and H2: WIN.** A small model should be poisoned more, and go stale more, reading raw reports.
- **H3: NON-INFERIOR.** One verified sentence leaves a small model little to get wrong.

## 5. Budget

- **Calls:** 2,000 per world, as in RM-1. That is 2,000 for dev and 16,000 for main.
- **Rate and tokens:** the deployment allows 200 requests and 200,000 tokens a minute. Small-model tokens are cheap.
