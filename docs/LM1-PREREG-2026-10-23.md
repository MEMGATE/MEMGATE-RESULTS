## Main run
- **Questions:** the 402 main questions (`runs/lm1-split.json`). 353 are scored without abstention: 160 time questions (58 knowledge update, 102 temporal reasoning) and 193 others (97 multi-session, 51 single session with the user's words, 45 with the assistant's words). 25 are abstention questions. The 24 preference questions are not scored.
- **Models:** GPT-4.1 (2025-04-14) and gpt-6.1-sol. Answers at temperature 0 for GPT-4.1 and the service's default for gpt-6.1-sol, as on dev.
- **Arms:** FULL, RETRIEVAL, LAYER (tested); MEMORY and ORACLE (descriptive).
- **The dated memory:** built by GPT-4.1 from every main history session, with the dev prompt (prompt hash `ef5c5b5cecbe`), before this freeze. Building it asks no question and reads no answer.

## Measures
- **Primary: blind hand labels.** Every FULL, RETRIEVAL and LAYER answer of both models to a scored question is labelled right or wrong under the guide. The labeller sees the question, its date, the reference, whether it is an abstention question, and the answer's final line. The labeller does not see the arm or the model, and items are shuffled over ten files.
- **Secondary: the code scorer** (`right()`), for every arm.
- **Accuracy:** the share of questions answered right, over all scored questions without abstention ("all"), the time questions ("time"), and the others ("other").
- **Validity:** for each model, each tested arm leaves at most 2% of questions unanswered. Otherwise that model's tests are INVALID.

## Hypotheses
Each test is paired by question, with a 95% bootstrap interval (10,000 resamples, seed `LM1-BOOT`), and is run for each model.

| Test | Comparison | Questions | Rule | Prediction for GPT-4.1 | Prediction for gpt-6.1-sol |
| --- | --- | --- | --- | --- | --- |
| H1 (primary) | LAYER − RETRIEVAL | all | WIN if the lower bound is above 0 | WIN | WIN |
| H2 | LAYER − FULL | time | WIN if the lower bound is above 0 | WIN | NOT SHOWN |
| H3 | LAYER − FULL | all | NON-INFERIOR if the lower bound is above −5 points | NON-INFERIOR | NOT SHOWN |

**What counts as failure:** H1 NOT SHOWN for either model means the dated memory did not add to retrieval for that model. Every verdict is reported as it comes, with the code scorer's verdict beside it.

## Reported, without a test
- Accuracy per question type and per arm, MEMORY and ORACLE included, by both measures.
- Abstention questions (25): right answers per arm.
- Prompt tokens per question, per arm.
- How often the retrieved rounds held the answer.
- The code scorer's agreement with the hand labels on main.

## Limits
- LongMemEval's own scoring uses GPT-4o as a judge. The lab uses no outside model to judge, so these numbers are not directly comparable with published ones.
- The hand labels are the lab's own, made blind to arm and model.
- The memory is built by a model, so its errors are part of what is measured.
- BM25 is a simple retriever.
- The layer's gate, scopes and undo are not tested: LongMemEval has one trusted user and no attacker.
