**Status: FROZEN on 27 October 2026, 20:34 IST, before any BL-2 main world was packed or run.** Drafted at 20:24. ## Why
The first question a lab asks of a learner that writes facts into a model's weights: why not keep the facts outside and give the model the right ones in its prompt (retrieval-augmented generation)? BL-2 answers it on the learner's own worlds and questions. RAG gets the same stream, in two forms:
- what the stream reported;
- what the learner's own gate admitted.

## The arms
Both use the untouched Qwen2.5-7B-Instruct (revision `a09a35458c70…`, 16 bits), loaded and asked as CCL-4's kernel asks: the same answering code, greedy decoding, the same token limits and batches. No training.
- **RAG-STREAM.** The memory is what the stream reported as NAIVE receives it: every source, liars and registry errors included. For each office it holds the last value each session's reports gave it, with the date it was first reported.
- **RAG-GATE.** The memory is what the learner's own gate admitted (CCL-4's registry-checked gate, recorded session by session as CCL-4's plan runs it, behaviour unchanged). It leaves out values the registry later showed were never true, as the learner does. This is the memory SYSTEM2 learned, given in the prompt instead.
- **Retrieval.** This applies to questions about offices (office, local, wrong, follow, dated). The arm takes the offices whose subject is named in the question, then those whose holder (now or earlier) is named, at most five. Each is written as a line into the question's system message under "Facts you have:": the holder since a date, and earlier holders until their dates.
- **Other questions.** Questions of other kinds (skills, GSM8K, MMLU) are asked unchanged, as the learner's scope rule leaves them to the untouched model.

## Design
- **Worlds.** 9702 and 9703, CCL-4's main worlds. Every question is CCL-4's own: the packer checks that common, per-evaluation and lie items equal CCL-4's payloads. Memories and answers are taken after session 12.
- **Pack.** `PYTHONHASHSEED=0 python cl/bl2.py pack 970X:main runs/bl2-main-7b/w970X --evals 12 --questions-from runs/ccl4-main-7b-colab/w970X/dataset/payload.json --prereg docs/BL2-PREREG-2026-10-27.md`.
- **Machine.** Azure's serverless A100 (`cl/aca_run.py`).
- **Comparison arms.** CCL-4's 7B runs of the same worlds: SYSTEM2 as routed by its scope rule, and the untouched model. This reuse is declared; those results were known at freezing.

## Comparisons
SYSTEM2 − RAG-STREAM and SYSTEM2 − RAG-GATE, each after session 12, with worlds pooled. Each uses a paired bootstrap over items within each world: 10,000 resamples, seed 12345, 95% percentile intervals.

| R | Measure | Rule |
| --- | --- | --- |
| R1 | Attacker values answered | WIN if the upper bound is below −1 point |
| R2 | Current holders | NON-INFERIOR if the lower bound is above −5 points |
| R3 | Never-streamed offices | NON-INFERIOR if the lower bound is above −5 points |
| R4 | Offices told by session 4, holder unchanged since (none attacked) | NON-INFERIOR if the lower bound is above −5 points |
| R5 | Dated questions | NON-INFERIOR if the lower bound is above −5 points |
| R6 | What follows from a change | NON-INFERIOR if the lower bound is above −5 points |
| R7 | GSM8K and MMLU | NON-INFERIOR if the lower bounds are above −3 and −2 points |

The rules are the same for both arms. A verdict on the wrong side is reported as a loss to retrieval.

## Predictions
- **Against RAG-STREAM:** R1 WIN, because retrieval of the raw stream puts attackers' values in the prompt. R2 to R7 NON-INFERIOR.
- **Against RAG-GATE:** R1 NOT SHOWN, because both rest on the same gate. For R2, R5 and R6 there is no prediction: with the gate's facts and dates in the prompt, retrieval may match or beat the trained weights on current holders, dates and what follows. R3, R4 and R7 NON-INFERIOR.
- **What the learner offers over RAG-GATE, if the numbers are equal:** no retrieval at answer time, and the skills and general rules it trains. The result states this as an argument, not as a measured win.
