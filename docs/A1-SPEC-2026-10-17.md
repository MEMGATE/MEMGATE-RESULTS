# A-1: Nyāya upamāna and Indra's Net for cross-domain transfer

**Status:** design, written on 17 October 2026 before any A-1 code was run. No model calls.

## 1. Question

**Nyāya upamāna.** Nyāya counts *upamāna*, knowing by likeness, as a separate pramāṇa. The standard example: told that a *gavaya* is like a cow, one recognises the gavaya on first sight.

**Indra's Net.** This is comparative (Buddhist Avataṃsaka/Huayan, with a Vedic seed in Atharvaveda 8.8). Each jewel in the net reflects all the others, so any part carries the structure of the whole.

**Question.** After learning one world, A, does a learner pick up an analogous world, B, faster if it can carry its lessons across by likeness?

- B has the same hidden rules as A, but its features are renamed and reordered, and its values are relabelled.
- The labels keep their names: the "word" is known, the "appearance" is new.

## 2. Worlds and streams

| Item | Specification |
| --- | --- |
| Source world A | an SR family world (EXC, UPA or DNF) with seed `s`, 400 cases |
| Target world B | the same rules, with a seeded random permutation of the 12 features and, per feature, a random relabelling of values `v*` → `u*`; 200 fresh cases from the same generator |
| Learner's stream | the 400 A cases, then the 200 B cases |
| Score | prequential accuracy on B's first 100 cases (transfer); B's full 200 cases are also reported |
| Seeds | dev 0–4; main 10000–10019 per family (60 pairs) |

## 3. Arms

All arms use R-ORD's lesson machinery.

| Arm | What it does |
| --- | --- |
| **SCRATCH** | learns B with a fresh learner |
| **POOLED** (ordinary continual learner) | keeps A's memory and lessons and simply continues into B. A's lessons never match B literals, and A's cases sit in the 1-NN memory. |
| **UPAMANA** | keeps A's learner. From the 10th B case on, before each prediction, it re-estimates a feature-and-value mapping B → A by likeness, translates A's validated lessons into B literals, and stores them as validated (see below). |
| **INDRA** | UPAMANA, plus a net-consistency check (see below) |
| **ORACLE** | translates A's lessons with the true mapping from the 10th B case on. This is the upper bound. |

### How UPAMANA estimates the mapping

1. **Profiles.** Each literal in A and in B gets a label profile: the frequency of each label among the cases that contain the literal.
2. **Feature matching.** Each B feature is matched one-to-one to the A feature whose value profiles fit best. The fit is the sum, over values, of the best per-value profile similarity. Matching is greedy, best pairs first.
3. **Value matching.** Within a matched feature pair, values are matched greedily by profile similarity.
4. **Storage.** Translated lessons are stored as validated. Upamāna is a pramāṇa in Nyāya: knowledge by likeness is accepted as knowledge, and ordinary revision corrects it when B contradicts it.

### What INDRA adds

A translated lesson is admitted only if no B case seen so far contradicts it. The candidate is "reflected" against the whole net of B experience before entry.

## 4. Hypotheses and decision rules

The decision rules are the same as SR-1, with strata = families and units = pairs.

| Hypothesis | Comparison | Measured on |
| --- | --- | --- |
| **H1 (primary)** | UPAMANA − SCRATCH | B's first 100 cases |
| H2 | INDRA − SCRATCH | B's first 100 cases |
| H3 | INDRA − UPAMANA | B's first 100 cases |
| H4 | POOLED − SCRATCH | B's first 100 cases; does carrying unmapped memory help or hurt? |
| Descriptive | ORACLE − SCRATCH | the ceiling |
| Descriptive | mapping accuracy | share of B features mapped to their true A feature, after 10, 30 and 100 B cases |

The run is **INVALID** if no translated lesson is ever stored in UPAMANA.

## 5. Predictions before any A-1 code

| Comparison | Prediction | Reason |
| --- | --- | --- |
| ORACLE − SCRATCH | Large gain (several pp) on B's first 100 cases | The true mapping carries A's lessons over intact. |
| UPAMANA | Positive only where the mapping becomes accurate early | Profiles from 10 to 30 cases are noisy, so expect UNDETERMINED or a small WIN on EXC and UPA, and less on DNF. |
| INDRA − UPAMANA | Positive | It filters wrong translations. |
| POOLED − SCRATCH | ≤ 0 | A's cases distract 1-NN. |
