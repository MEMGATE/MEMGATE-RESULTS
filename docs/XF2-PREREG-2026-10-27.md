# XF-2 preregistration: CCL-4's test on a sparse mixture-of-experts model, OLMoE-1B-7B (frozen)

**Status: FROZEN on 27 October 2026, 22:47 IST, after the two-session dev run on the A100 (`runs/xf2-dev-olmoe/w9792-s2`) showed the frozen kernel runs OLMoE end to end, and before any XF-2 main world was packed.** Drafted at 21:03 IST; only this status line and the dev run's section below were added at the freeze. This covers Gemini's blind spot that continual-learning tests run on dense models while frontier models are mostly sparse mixtures of experts. It falls under item 2 of the package's fixed list (Gemini's points), and was added at the founder's request at 20:55 IST.

## The system under test
SYSTEM2, CCL-4's learner, unchanged, run by CCL-4's frozen GPU runner in Colab's layout (`colab_pack.colab_kernel("7b", 4)`, SHA-256 `a5567bf0…`), which loads whatever model the payload names, in 16 bits. ## Design
- **Model.** `allenai/OLMoE-1B-7B-0924-Instruct` at revision `7f1c97f440f06ce36705e4f2b843edb5925f4498`. It is a fully open mixture-of-experts model (Apache 2.0): 64 experts, 8 active per token, about 1B of its 7B parameters active.
- **Worlds.** 9702 and 9703, CCL-4's main worlds with CCL-4's options. The packer checks that every question equals CCL-4's payloads.
- **Arms.** SYSTEM2, then NAIVE, and the untouched model.
- **Machine.** Azure's serverless A100 (`cl/aca_run.py`).
- **Pack.** `PYTHONHASHSEED=0 python cl/xf2.py pack 970X:main runs/xf2-main-olmoe/w970X --arms SYSTEM2,NAIVE --questions-from runs/ccl4-main-7b-colab/w970X/dataset/payload.json --prereg docs/XF2-PREREG-2026-10-27.md`.

## The dev run (dev world 9792, two sessions; 27 October, 21:51–22:40 IST)
- **End to end.** The frozen kernel loaded OLMoE and ran every step: the untouched model answered all 2,290 questions; SYSTEM2 trained two sessions (509 and 501 rows) with its practice rounds; NAIVE trained two sessions (542 and 516 rows); exit code 0 and the done line.
- **Answers.** OLMoE answers in full sentences that name the person within the answer budget (for example "The director of the British Broadcasting Corporation (BBC) is Tim Davie."). CCL-4's scoring reads them as it reads every model's answers.
- **Time on the A100.** The untouched model's 2,290 answers took 1,189 seconds (Qwen2.5-7B: 142 seconds for 2,103). A session's training took about 258 seconds for SYSTEM2 and 214 for NAIVE (Qwen2.5-7B: 46–49 and 33–39). So a main world takes about 5 to 8 hours, against about one hour for Qwen2.5-7B. This is the runtime part of the blind spot, and the result reports it.

## Predictions
OLMoE is a small model in what it computes per token (about 1B active), so its untouched answers and general scores are expected to be lower than the dense 7B models'.
