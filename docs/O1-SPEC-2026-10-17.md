# O-1: Sāṃkhya tattva ontology vs flat and random groupings

**Status:** design, written on 17 October 2026 before any O-1 code was run. No model calls are made.

## 1. Question

Sāṃkhya enumerates 25 tattvas:

- puruṣa and prakṛti;
- buddhi, ahaṃkāra and manas (the internal instrument);
- four pentads of five: the jñānendriyas, karmendriyas, tanmātras and mahābhūtas.

The Śaiva systems extend this list to 36. Vaiśeṣika instead classifies everything into padārthas.

What an ontology like this offers a learner is grouping: it says which features belong together.

**The question:** when a domain's features really do fall into such groups, does a learner that is given the grouping (as derived, group-level features) learn better than one of these?

- A flat learner, which gets no derived features.
- A learner given a **random** grouping of the same shape, which isolates whether the right categories matter or merely having categories.

**Honest caveat.** The worlds are built with a Sāṃkhya-shaped grouping. O-1 therefore tests whether a correct ontology helps and a wrong one does not. It does not test whether the Sāṃkhya classification describes reality. There is no real dataset with a known tattva grouping, and assigning tattvas to features of an existing dataset by hand would be my invention.

## 2. Worlds

Each world has 23 binary-valued categorical features (values `v0`/`v1`), modelled on 20 of the 25 tattvas. The group structure is the 4 pentads plus the 3 antaḥkaraṇa singletons; puruṣa and prakṛti are not observable features.

| Group | Size |
| --- | --- |
| P1 (jñānendriya-like) | 5 |
| P2 (karmendriya-like) | 5 |
| P3 (tanmātra-like) | 5 |
| P4 (mahābhūta-like) | 5 |
| buddhi, ahaṃkāra, manas | 3 singletons |

**Families**

| Family | Labelling rule |
| --- | --- |
| ANY | L1 iff some feature of one pentad Pa is `v0` AND some feature of another pentad Pb is `v0`. P(v0) is 0.2, so "some" is informative. |
| COUNT | L1 iff at least 2 features of pentad Pa are `v0`. |
| MANAS | L1 iff manas = `v0` AND some feature of Pa is `v0`. The singleton is combined with a group property. |
| FLATRULE | L1 iff two specific individual features are both `v0`. The grouping is irrelevant here; this family measures cost. |

**Seeds.** Dev seeds 0–4; main seeds 11000–11019 per family. Each stream has 400 cases.

## 3. Arms

Each arm is a learner paired with a feature view.

**Learners:** R-ORD, EXT-DT and EXT-NB.

**Views:**

- **flat:** the 23 raw features.
- **onto:** the raw features plus, for each true group of size ≥ 2:
  - an `any_v0` flag;
  - the count of `v0`, as a category (0 to 5).

  This adds 8 derived features.
- **rand:** the same 8 derived features, built over a random partition of the 23 features into groups of the same sizes (seeded).

## 4. Hypotheses and decision rules

The SR decision rules apply. Strata are families and units are worlds.

| Hypothesis | Comparison | Families |
| --- | --- | --- |
| **H1 (primary)** | R-ORD:onto − R-ORD:flat | ANY, COUNT, MANAS |
| H2 | R-ORD:onto − R-ORD:rand: does the right grouping matter? | ANY, COUNT, MANAS |
| H3 | R-ORD:onto − R-ORD:flat: the cost when the grouping is irrelevant | FLATRULE |

The same comparisons are reported for DT and NB, descriptively.

## 5. Predictions

- **H1:** WIN, by construction.
- **H2:** WIN. A random grouping should not help.
- **H3:** about 0 or slightly negative.

As in T-1, a WIN here shows that a correct grouping helps. It does not show that the Sāṃkhya grouping is correct for any real domain.
