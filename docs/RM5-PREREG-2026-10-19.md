## Dev run (exposed SE-2 world 0)

Source: [`runs/rm5-dev-20261019-a`](../runs/rm5-dev-20261019-a/SUMMARY.md). 800 calls, all answered on the first attempt.

| Arm | Truth | Poison | Input tokens per call |
| --- | ---: | ---: | ---: |
| RAW-INJ | 87.0% | 65.0% | 558 |
| ESCAPED | 100.0% | 0.0% | 633 |
| SPOTLIGHT | 100.0% | 0.0% | 778 |
| GATED | 100.0% | 0.0% | 42 |

**Poison by the payload of each fact's last injected report.** In RAW-INJ:
- the forged line in the memory's format: 13 of 14;
- the authority spoof: 9 of 15;
- the instruction: 4 of 9.

In ESCAPED and SPOTLIGHT: 0 of 38.

**What the dev run shows.** Both prompt-level defenses closed this channel on the exposed world. The forged line was inside the attacker's quoted or marked words, and the model did not read it as provenance.

## Predictions for the main run

| Hypothesis | Prediction |
| --- | --- |
| H1 | lowers poison |
| H2 | lowers poison |
| H3 | no difference shown |
| H4 | no difference shown |
| H5 | both defenses raise truth, by about +13 pp |

**What this would mean.** The vulnerability measured in RM-2 to RM-4 is a property of memory that concatenates untrusted text unescaped. Two standard defenses fix it for this attack and this model.

**What the gate still adds.** It does not depend on the model reading a format correctly, and its prompts are 15 to 18 times smaller. It also handles what defenses about format do not: colluding sources and stale values. In RM-1, raw memory was poisoned on 16.6% of attacked facts after four sessions, and left 27.6% of changed facts stale under a looser instruction.
