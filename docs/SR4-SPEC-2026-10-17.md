# SR-4: arthāpatti (postulation) and syādvāda/nayavāda (standpoints), plus the grand mix

**Status:** design, written on 17 October 2026 before any SR-4 code was run. No model calls are made.

## 1. Mechanisms

**ART: arthāpatti, postulation** (a pramāṇa in Mīmāṃsā and Advaita). "Devadatta is fat but does not eat by day, so he eats at night": when the known facts exclude every other explanation, the remaining one is postulated.

- **When it runs:** only when no lesson decides a case.
- **What it does:** each established literal of the case that has at least 6 observations (2 × the support threshold) allows only the labels seen with it.
- **The decision:** if the labels allowed by all such literals together come to exactly one label, that label is postulated. Otherwise the ordinary fallback decides.
- **What is new:** R-ORD has no knowledge of exclusions.

**SYA: syādvāda and nayavāda, standpoints** (Jaina; used comparatively, not as Sanatana). A claim holds *syāt*, "in some respect", and different standpoints (*naya*) see different sides of it.

- **The standpoints:** when no lesson decides, the fallback asks 7 standpoints instead of one 1-NN. Seven matches the seven predications of the *saptabhaṅgī*.
- **How each standpoint looks:** it is a fixed, seeded subset of half the features, and it runs 1-NN on that subset.
- **The answer:** the majority label wins. Ties go to the earlier standpoint.
- **In ML terms:** this is a random-subspace nearest-neighbour ensemble.

**MIX-SR4:** R-ORD with ART and SYA.

**MIX-GRAND:** R-ORD with ANU (the best real-data result so far), ART and SYA. KALA is left out because it was neutral on stationary real data (H-1).

## 2. Arms

EXT-DT, EXT-NB, EXT-1NN, R-ORD, R-ORD+ART, R-ORD+SYA, MIX-SR4 and MIX-GRAND.

**Amendment before any SR-4 code.** The first draft listed only the six two-class datasets. With two classes, a literal can exclude a label only when it is pure, so arthāpatti's elimination would reduce to "follow a pure literal". The three multi-class datasets were added before any mechanism code was written or run, so that elimination across several labels is actually exercised.

## 4. Hypotheses and decision rules

The decision rules are the same as in SR-1 to H-1.

| Hypothesis | Comparison |
| --- | --- |
| **H1 (primary)** | MIX-GRAND − R-ORD, on the nine held-out datasets |
| H2 | R-ORD+ART − R-ORD |
| H3 | R-ORD+SYA − R-ORD |
| H4 | MIX-SR4 − R-ORD |
| Descriptive | MIX-GRAND − EXT-NB and − EXT-DT |

The run is INVALID if ART never postulates or SYA never runs in its own arm on the held-out data.
