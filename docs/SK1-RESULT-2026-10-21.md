## What it shows
- **The gated library made all six models pass every program.** The library holds only the recipes that hold in the release the code runs on. With it, every model rewrote all 30 programs so that they run on pandas 3.0.6 and print what they printed before.
  - Three models could not do this on their own: they passed 20–63% of programs with no library.
- **A poisoned library broke the models that most needed help.** With half its recipes replaced by an attacker's, grok-4.7, gpt-4.1-base and llama-4-maverick used an invented function or package in 83% of programs, and passed 13–17%.
- **The strongest models mostly ignored the fake recipes.**
  - claude-opus-5-5 and gpt-6-astra never used them.
  - gpt-6.1-sol used one in 2 of 30 programs.
- **What the gate checks.** It admits a recipe only if every name it uses exists in the installed release, and it never installs anything. Before the run it admitted all 24 true recipes and none of the 24 attackers'.

## Limits
- **Scope:** one library (pandas) and one kind of skill (API migration). The programs are short and built from snippets of three changes each.
- **The attackers' recipes are inventions.** A recipe that uses real but wrong functions would pass the gate; catching it needs a test run of the recipe itself.
- **The attack is strong:** the poisoned library replaces half the recipes.
- **This is the memory route.** The same skills learned into the weights are SK-2, queued for Azure's GPUs.
