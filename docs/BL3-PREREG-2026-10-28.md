# BL-3 preregistration: the learner with retrieval, against retrieval alone, on CCL-4's worlds (7B) (frozen)

**Status: FROZEN on 28 October 2026, 12:35 IST, before any BL-3 world was packed for a run or run.** Part B item 10 (`docs/PARTB-PLAN-2026-10-28.md`). No dev run on a GPU: the packer and the analysis were checked on the CPU (world 9702: the 909 retrieval questions built here equal BL-2's RAG-GATE questions item by item; the report ran end to end on stand-in answers).

## Why
BL-2 (`docs/BL2-RESULT-7B-2026-10-28.md`) found that the untouched model with the gate's facts in its prompt (RAG-GATE) answers dated questions and what follows from a change better than the trained learner (by 11.56 and 17.14 points). A lab will ask: then why train at all? BL-3 asks whether learning adds anything when retrieval is there too, and whether the learner with retrieval keeps everything retrieval gives.

## The system under test
**LEARNER+RAG:** CCL-4's learner SYSTEM2, unchanged, trained over CCL-4's twelve sessions by CCL-4's frozen GPU runner. After session 12 it is asked BL-2's RAG-GATE questions: the same questions with the same retrieved facts in their system message, built by BL-2's own code from the same recorded gate. Each question is answered by the model CCL-4's scope rule picks for the original question, as SYSTEM2 is always scored: the trained weights when the rule routes it there, else the untouched model. Questions with no retrieved facts are asked as they are.

## Design
- **Model.** Qwen2.5-7B-Instruct (revision `a09a35458c70…`), 16 bits, on Azure's serverless A100 (`cl/aca_run.py`).
- **Worlds.** 9702 and 9703, CCL-4's main worlds, with CCL-4's options: 40 registry errors believed in session 1 and corrected in session 4, 12 sessions. The packer checks that every question equals CCL-4's payloads and that every retrieval question equals BL-2's.
- **Arm run here.** SYSTEM2 alone; the untouched model answers every question at session 0, the retrieval questions included.
- **Comparisons.** BL-2's runs of the same worlds (`runs/bl2-main-7b/w970X`, RAG-GATE), whose results are known (declared), and this run's own SYSTEM2 without retrieval.

**The claim tested:** with retrieval added, the learner keeps everything retrieval alone gives (B4–B8) and adds what retrieval cannot give (B3: the trained rewrites). B1 and B2 test whether the trained weights also make retrieved facts more useful. **Reported, not judged:** this run's untouched model with retrieval beside BL-2's (a check that the two runs answer alike), and every measure's level per world.

## Predictions
- **B3 WIN:** the untouched model rewrites almost none of the code changes (CCL-4: 0–4%), the learner about half.
- **B4 NON-INFERIOR:** both arms rest on the same gate and answered no attacker value in BL-2 and CCL-4.
- **B5–B8 NON-INFERIOR.**
- **B9 and B10 WIN:** retrieval helped the untouched model on dated questions and what follows; it should help the learner too.
- **B1 and B2: no direction predicted.** The trained weights may add to the retrieved facts or compete with them. A result of not shown means learning adds nothing there beyond retrieval; wrong side means it gets in the way. Each is reported as it comes out.

## Validity
A world is valid if SYSTEM2 finished its 12 sessions (exit code 0, the done line) and, after session 12, answered every question, the retrieval questions included, and the untouched model answered every question. A run stopped by the machine without output is rerun once with the same payload, in a new folder.
