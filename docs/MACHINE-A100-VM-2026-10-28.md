## How runs run on it (`cl/vm_run.py`)
- **Setup, once:** a Python environment with CUDA PyTorch (torch 2.5.1, CUDA 12.4 wheels) and numpy.
- **Each run:**
  - the run's own payload goes to `/content/input/payload.json`;
  - its own kernel (`colab/kernel.py`) runs once with `python -u`;
  - the outputs go to `/content/working` and are fetched into the run's `kaggle-output/`.

  These are the same Colab paths and the same script as the Azure Container Apps jobs. The kernel installs its pinned transformers, peft and accelerate at start, as it does there.
- **One run at a time.** `vm.json` in the run's folder records the host and times, as `aca.json` does for jobs.
- **Model mounts:** runs that mount models from the jobs' share (Llama and Gemma) stay on Container Apps.

- The same GPU model (A100 80GB PCIe).
