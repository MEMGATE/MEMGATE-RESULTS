# RP-1: six winners replicated together on a tenth fresh pool

**Status:** design, written on 18 October 2026 before any RP-1 code. No model calls are made.

## 1. Question

Six effects have won at least once in a preregistered test. Do they hold again, unchanged, on data none of them has seen?

| Code | Effect | Source | Original result |
| --- | --- | --- | --- |
| R1 | Jijñāsā: ask for the label only under doubt (JIJNASA − RANDOM-ASK) | JK-1 H1 | +3.69 pp |
| R2 | Kṣetrajña: answer only where a lesson decides (KSETRAJNA − RANDOM-ABSTAIN, selective accuracy) | JK-1 H2 | +7.08 |
| R3 | Pāṇinian pratyāhāra: range literals for the lesson learner (R-ORD on the range view − R-ORD) | PN-1 H1 | +1.19 |
| R4 | The pariṣad: PARISHAD-3* − its lesson member R-ORD+ANU+AKH | P-2 H1 | +1.60 |
| R5 | The assembly asks only under doubt (SABHA-JIJNASA − SABHA-RANDOM-ASK) | PV-1 H4, MX-2 H1 | +3.94, +3.19 |
| R6 | The assembly answers only when of one mind (FULL-EKAMATA − random abstention, selective accuracy) | MX-2 H2 | +7.88 |

**The code is not changed.** Each effect is computed with the code that produced its original result:
- `jk1.run_jk1`;
- `ranges.view(…, "range")` with `harness.run_stream("R-ORD", …)`;
- `pv1.run_full`;
- `mx2.run_mx2`.

## 3. Decision rules

Each of R1–R6 is judged by the usual rule (WIN: point ≥ +1.0 pp and CI lower bound > 0; NO WIN: CI upper bound < +1.0; otherwise UNDETERMINED). The CI is stratified by dataset.

An effect **replicates** if its point estimate is positive and its CI lower bound is above 0. This is a weaker bar than WIN, because the original WINs were already decided.

There is no correction for testing six effects at once. The six are reported side by side.
