## Rules fixed in the code

**Doubt.** JIJNASA doubts when the fallback answered, or when the deciding lessons have fewer than 6 supports in total (`2 × SUPPORT_MIN`).

**Matched controls.**
- RANDOM-ASK observes exactly as many labels as JIJNASA asked in the same run, at cases drawn by `random.Random(order seed + 777)`.
- RANDOM-ABSTAIN answers as many of FULL's scored cases as KSETRAJNA answered, drawn by `random.Random(order seed + 999)`.

**Scoring.** Every case except case 0 is scored, as in the harness. If no lesson decides any case in a run, both selective arms answer nothing, and that run counts 0 for H2.

**INVALID conditions:**
- any non-determinism in the repeats;
- a failed run;
- JIJNASA asking for every label in every run;
- no lesson deciding any case in any run.

## Dev run (exposed data)

The output is in [`runs/jk1-dev-20261017-a`](../runs/jk1-dev-20261017-a/SUMMARY.md). It covers the 26 held-out datasets of SR-4, SR-7 and Y-1, whose main runs are over, in orders 2000–2009. There were 260 runs, all 26 repeats were identical, and nothing failed.

| Comparison | pp, 95% CI | Verdict |
| --- | --- | --- |
| H1: JIJNASA − RANDOM-ASK | +4.18 [+3.62, +4.77] | WIN |
| H2: KSETRAJNA − RANDOM-ABSTAIN (selective accuracy) | +5.17 [+4.66, +5.64] | WIN |
| FULL − JIJNASA | +2.44 [+2.10, +2.80] | descriptive |
| FULL − RANDOM-ASK | +6.63 [+6.03, +7.25] | descriptive |

**Findings.**
- **JIJNASA asked for very different shares of the labels.** It asked for 1.3% on bank and 2.0% on seismic, but 96% on abalone, where lessons rarely form.
- **On noisy or imbalanced data, asking only under doubt even beat observing every label.** Examples: blood +4.5 pp, plrx +5.2, fertility +2.9, seismic +2.9. Not observing confident cases keeps noisy counterexamples from breaking good lessons, the same effect as akhyāti in SR-6.
- **On clean data with many fine distinctions it lost to FULL.** Wall-following robot −17.6 pp, musk −13.8, urban −11.8, shuttle −7.9. This is the limit named in the spec: a confident but wrong lesson is never corrected, because its cases are never asked about.
- **Lesson-decided cases are much more accurate than the matched random subset on 26 of 26 datasets.** The fallback cases are the weak ones.

No bug was found, and nothing changed after the dev run.
