## What this means

Seven partial standpoints are better than one full view **when the signal is spread over many weak, noisy features and there are few classes**. Adult, bank, mammographic mass, German credit and Connect-4 all show this, and so does the synthetic DRIFT family. A standpoint that sees half the features ignores some of the noise that misleads full-feature 1-NN.

Partial standpoints fail **when the classes are many or the label needs all features together**:

- letter, with 26 classes;
- yeast, with 10;
- in the dev run, the 18-class chess endgame KRK and the car evaluation function.

There, a half-view loses exactly the detail that separates the classes.

In Jaina terms, each *naya* is true "in some respect". The experiment shows that a vote among partial views is a good policy only for some kinds of data. As a single default it costs 0.68 pp across this pool.

These five subsets were not preregistered, so the split by number of classes is exploratory. It is consistent across both the dev and main runs. A preregistered test would need a rule that chooses the standpoint vote by the number of classes, fixed in advance.

**Arthāpatti as defined here is inert.** Exclusion by single literals adds no information beyond what the lessons and the fallback already use.

## Limits

- Nine datasets, with the H-1 binning rule fixed in advance.
- Shuffled orders.
- Model-free.
- Comparative Jaina syādvāda is represented only as a subspace vote. The saptabhaṅgī's seven predicate forms are not modelled as truth values.
