# ML-7 preregistration: frozen before the main run

18 October 2026. This freezes ML-7 as defined in the [spec](ML7-SPEC-2026-10-18.md).

- Code SHA-256: `76044fd594aee6f03e9f524d68ed11542fe14694b18e6f59ba828fc5f36b9df2`. It is the same code as the smoke and dev runs (commit `bd9ab965`; later commits changed only documents and run records).
- Model: gpt-6.1-sol.
- Main worlds: synthetic EXC, NOISE and DRIFT at the new seeds 39000–39005, 100 cases each. That gives 18 worlds and about 8,000 calls.

## Rules fixed in the code

**The prompt.** It is ML-1's prediction prompt. Its last instruction becomes "Reply with the label, then the word SURE if the experience shown makes you confident of it, or UNSURE if it does not."

**Parsing.** SURE counts only when the reply says SURE and not UNSURE; anything else counts as UNSURE.

**Asking and the random controls.**
- SELF-JIJNASA observes the first 10 cases, then those where the model says UNSURE.
- SELF-RANDOM-ASK observes the first 10, then as many later cases at random, drawn by `random.Random(seed + 777)`.
- H1's random answers are drawn by `random.Random(seed + 999)`. A world with no SURE case counts 0.

**INVALID conditions:**
- failures plus refusals above 2% of calls;
- unparseable labels above 2%;
- a crashed world.

## Runs before the freeze (exposed seeds)

**Smoke run.** It is in [`runs/ml7-smoke-20261018-a`](../runs/ml7-smoke-20261018-a/SUMMARY.md): DRIFT, 30 cases, 150 calls, 0 failures.

**Dev run.** It is in [`runs/ml7-dev-20261018-a`](../runs/ml7-dev-20261018-a/SUMMARY.md): seed 0 of each family, 1,360 calls, 0 failures, 0 refusals, 0 unparseable labels.

| Family | SELF-FULL | SELF-JIJNASA | SELF-RANDOM-ASK | Labels asked | SURE share | Accuracy when SURE | Accuracy when UNSURE |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |

| NOISE | 73.7 | 64.6 | 64.6 | 33% | 70% | 84.1 | 50.0 |
| DRIFT | 65.7 | 62.6 | 50.5 | 18% | 61% | 75.0 | 51.3 |

| Comparison | pp |
| --- | --- |
| H1: SURE − random | +7.76 |
| H2: SELF-JIJNASA − SELF-RANDOM-ASK | +6.73 |
| SELF-JIJNASA − SELF-FULL | −4.71 |

Each family has a single world, so these intervals are degenerate.

**Findings.**
- **The model's SURE is informative.** Its answers were 24–34 pp more accurate when it said SURE than when it said UNSURE.
- **The model says SURE on 61–85% of cases.** Asking only when it says UNSURE used 18–33% of the labels.

No change was made after the smoke run.
