**Findings.**

- **Akhyāti helps where the data are noisy and duplicate-rich:** flare +3.72 pp, mammographic +3.52, SPECT +1.24.
- **Akhyāti hurts on Elec2 (−2.02 pp).** It kept lessons through 1,001 indiscernible counterexamples there. In a drifting stream, an indiscernible contradiction is often a real change, not noise.
- **Pratyāhāra hurts on small or wide datasets:** zoo −3.8, promoters −2.2, audiology −2.0. Early on, the lessons use only a few features, so the fallback ignores features it still needs. It is ≈ 0 on the synthetic families. The prediction that it would help there was not borne out.
- **No bug was found in attempt b,** and nothing changed after it.
