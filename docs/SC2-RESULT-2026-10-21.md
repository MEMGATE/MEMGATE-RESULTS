## What it shows
- **Interference between versions of one fact is large, and it is about memory design.** A memory that appends every record and never supersedes leaves the old holders beside the new one. Without dates, every model was misled, from a quarter of the time (claude-opus-5-5, gpt-6.1-sol, gpt-6-astra) to most of the time (grok-4.7, gpt-4.1-base, llama-4-maverick).
- **Dates help, but not fully.** With the record date on each line, the strong models picked the newest, but gpt-4.1-base and llama-4-maverick still named a past holder 9.5% and 12% of the time.
- **The layer's memory removes the problem.** It states the current value and what it replaced. Every model then named the current holder 99.5–100% of the time.
- **Look-alike offices caused no collisions at this memory size,** as in SC-1's retrieval check.

## Limits
- **Mostly head coaches,** from one snapshot.
- **Short memories,** at most 15 lines per question.
- **Undated versions are one realistic case of an append-only memory, not every one.** Some keep dates, as VERSIONS does.
