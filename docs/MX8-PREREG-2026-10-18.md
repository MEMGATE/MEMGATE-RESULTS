# MX-8 preregistration: frozen before the main run

18 October 2026. This freezes MX-8 as defined in the [spec](MX8-SPEC-2026-10-18.md).

- Code SHA-256: `d06380139054e482676b4697aeeb37f031a5fec3591df25ae2fecc6d936c2f27` (commit `917bde86`).
- `shastra/mx5.py` is unchanged: git blob `05dd09fc`, as at MX-5's freeze.

**Main data.** Daily and Sports Activities: 9,120 five-second segments, 19 activities, 8 persons. It runs in the new orders 50000–50009, cut to 1,000 cases, which gives 10 runs, each with all four arms. No learner has seen it.

## Rules fixed in the code

**Sources (dsa3 columns).**
- Torso is 0–18, right arm 19–37 and right leg 38–56.
- The first column of each is its copy of the person.
- The arms without the locus use columns 1–18, 20–37 and 39–56.

**Failure.**
- Injected once per run by MX-5's `fail_from`, with the locus-carrying sources, from case 600 (`random.Random(f"MX5-FAIL:{seed}")`).
- A failing sensor garbles its own copy of the person as well.

**Arms.**
- SPIES and SPIES+LOCUS have no pieces.
- SUPERVISOR and SUPERVISOR+LOCUS have DISMISS, AUDIT, RESET and SAMSKARA, as in MX-5.

**INVALID conditions:**
- non-determinism;
- a crashed run;
- the supervisor never dismissing.
