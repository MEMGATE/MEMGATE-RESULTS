## What this means

**What the gaṇa does.**
- Pooling the values of a many-valued feature into a class by their behaviour (the ākṛtigaṇa reading of 1.1.27) lets the lesson learner state lessons over the class.
- It helped slightly but reliably on fresh data. It helped most where there are many such features (kdd_internet_usage +0.95), and beat a random pooling (+0.39).
- The gain is below the 1 pp margin, so it is not a WIN.

**Why it is small.** The lesson learner forms a lesson on a single value after 3 supports. The gaṇa shows a value's class only after 5. So the gaṇa mostly reaches values whose own lessons already exist, and helps only in conjunctions with other features.

**Dev and main disagreed in sign.** Dev on the exposed datasets gave −0.38; main gave +0.35. Both are small, and the effect depends on the data.

**Pāṇini's two class devices, compared.**
- Pratyāhāra (PN-1, contiguous stretches of ordered values) won: +1.19 pp.
- Gaṇa (listed classes of unordered values) gives +0.35, NO WIN.
