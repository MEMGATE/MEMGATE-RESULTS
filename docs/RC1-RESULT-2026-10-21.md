## What it shows
- **Knowing which stored values are likely stale lets memory keep itself fresher on the same budget.** It is just as fresh with roughly a third to over half fewer checks.
- **The gain comes from the kind of post.** A head coach changes far more often than a mayor. Ordering by the kind alone (KIND) did as well as the full estimate with the holder's tenure. The tenure bands add little here.
- **What it means for the facts layer:** FR-2's freshness estimate now does two jobs. It tells the answer how sure to be ("chance it still holds today: about N%"), and it tells memory what to check next.

## Limits
- **Scope:** office holders only, from one snapshot.
- **Simulated parts:** checks return the record's holder that day, and report arrival is simulated.
- **Selection:** the offices are the snapshot's, chosen by events after March 2024. The test window ends before 2024.
