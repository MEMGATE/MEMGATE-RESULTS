## Hypotheses and decision rules (unchanged from the spec)

Verdicts use the state after session 12. Each confidence interval is a bootstrap over the 8 worlds (10,000 resamples, seed 12345).

| Hypothesis | Comparison | Rule |
| --- | --- | --- |
| **H1 (primary)** | Poison: GATED-SE2 − GATED-SE1 | WIN if it falls by ≥ 1 pp and the CI's upper bound is below 0; otherwise NO WIN |
| H2 | Poison: GATED-SE2 − NAIVE | the same rule |
| H3 | Truth: GATED-SE2 − NAIVE | NON-INFERIOR if the CI's lower bound is above −5 pp |
| H4 | Retention: GATED-SE2 − NAIVE | WIN if ≥ +1 pp and CI lower bound > 0; NO WIN if CI upper bound < +1; else UNDETERMINED |
| H5 | Update: GATED-SE2 − NAIVE | the same rule as H4 |
