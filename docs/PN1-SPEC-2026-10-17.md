# PN-1: Pāṇinian *pratyāhāra*, naming a contiguous stretch of an ordered inventory, as range literals for lessons

**Status:** design, written on 17 October 2026 before any PN-1 code. No model calls are made.

## 1. Source and mapping

**Source.** Aṣṭādhyāyī 1.1.71 *ādir antyena sahetā*: an initial element, taken together with a final marker (*it*), denotes the whole contiguous stretch between them in the Śivasūtra inventory. For example, *aC* names every vowel and *haL* every consonant. A grammar rule can therefore speak of a whole contiguous class with one short name. The coverage register lists this device as SOURCE-ONLY.

**Mapping (mine).** A binned numeric feature has an ordered inventory, q0 < q1 < q2 < q3. Ordinarily a lesson's literal names one bin. A *pratyāhāra literal* names a contiguous stretch of bins, so one condition can say "q1 to q3".

The ordinary analogue is a threshold literal ("≤ q1", "≥ q2"), as used by tree learners. A threshold names only stretches that touch an end of the inventory. A pratyāhāra can also name an inner stretch.

## 2. Views

Each view is built once per dataset, before ordering.

| View | Features |
| --- | --- |
| flat | the H-1 binned features, as in every earlier experiment |
| thresh | flat plus, for every binned numeric feature, the four end-anchored stretches [q0–q1], [q0–q2], [q1–q3] and [q2–q3] |
| range | flat plus every contiguous stretch longer than one bin and shorter than the whole: the four end-anchored stretches plus the inner stretch [q1–q2] |

Each stretch is a yes/no feature. A missing value stays missing.

**Arms.** R-ORD, EXT-NB and EXT-DT, each on each view: nine arms.
