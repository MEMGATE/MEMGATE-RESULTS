## Changes after the dev run

### 1. Claude Opus 5.5 is replaced by gpt-6.1-sol

Opus 5.5 refused 75 of its 961 calls in the dev run. All 75 were prediction calls, and every one returned `stop_reason: "refusal"` with category `cyber`, on prompts containing only anonymised `f0=v1 … -> L1` cases.

- The refusals fell unevenly across arms: 15–29 invalid answers per arm. They would have biased the comparison.
- A fallback to another model would mix models inside one arm.
- So the main run uses gpt-6.1-sol, which showed none of this in its smoke run.

This false-positive pattern is itself a finding for Pramana and is reported in the result.

### 2. Rate limiting

Opus 5.5 also hit HTTP 429: 14 calls failed after 5 attempts, and 396 calls needed retries. The client now:

- reads `retry-after` and `retry-after-ms`;
- allows up to 8 retries;
- caps the backoff at 90 s.

The analysis now also reports retries.

Nothing else changed: arms, prompts, thresholds, parsing and the decision rules are the same as in the spec.

## Main run

Run once, from `claude_lab/`, with both keys in the environment:

```
python -m shastra.run_ml1 main --prereg docs/ML1-PREREG-2026-10-17.md --out runs/ml1-main-20261017 --workers 24
```

This covers 2 models × 3 families × 6 seeds = 36 worlds, which should take about 11,500 calls.

A completed run is never re-run or overwritten. If the run crashes, the crash and its cause are recorded here and in `LOG.md` before any repeat into a new folder.

## Decision rules (unchanged from the spec)

- **Strata:** model × family, 6 strata.
- **Δ:** the mean over strata of the per-stratum mean paired difference.
- **CI:** stratified bootstrap over worlds (10,000 resamples, seed 12345).

| Hypothesis | Comparison |
| --- | --- |
| **H1 (primary)** | VRTTI − ORD |
| **H2** | SHASTRA − ORD |
| **H3** | ORD − EXP and VRTTI − EXP |

| Verdict | Condition |
| --- | --- |
| WIN | Δ ≥ +1.0 pp and the CI lower bound > 0 |
| NO WIN | CI upper bound < +1.0 pp |
| UNDETERMINED | any other result |

The run is INVALID if any of these hold:

- more than 5% of calls fail after retries;
- VRTTI never rejects a proposal (this invalidates H1);
- SHASTRA never explains, hides or withholds a lesson (this invalidates H2);
- the leakage check fails.
