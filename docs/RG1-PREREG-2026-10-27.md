# RG-1 preregistration: the learner with no registry at all, on CCL-4's worlds (7B) (frozen)

**Status: FROZEN on 27 October 2026, 20:16 IST, before any RG-1 main world was packed or run.** Item 5 of the package's fixed list (`docs/GPU-RUN-PLAN-2026-10-27.md`).

## Why
Every result so far uses a registry: a trusted source the gate asks, within a budget, about values in doubt. A lab will ask how much of the learner's resistance to lies rests on it. RF-1 (21 October, model-free, 20 worlds) showed the lab's registry-free gate admitting no attacker value with no registry at all. RG-1 puts that gate inside the learner and trains the 7B end to end.

## The system under test
SYSTEM2-FREE is CCL-4's SYSTEM2, built by CCL-4's own code (`clx.payload`, `ccl2.plan`), with two things replaced at run time. No frozen file changes.
- **Admission.** RF-1's registry-free gate (`memgate.free.FreeGate`, defaults: a value enters when at least 3 independent, established sources hold it, claimed in at least 2 steps; a source is established after 20 claims in 2 steps) replaces the registry-checked gate. The registry's own reports are not heard.
- **The plan's registry lookups** are answered from the gate's own memory (the steps at which it settled each value) instead of the registry. These lookups decide when an earlier holder last held a post, and whether a replaced value was a real holder.

The learner never asks the registry anything. The registry's errors are never heard, so the removal step has nothing to remove.

## Hypotheses
All after session 12, with worlds pooled. Each uses a paired bootstrap over items within each world: 10,000 resamples, seed 12345, 95% percentile intervals. SYSTEM2-FREE is scored as routed by its own scope rule (what it learned).

| G | Comparison | Rule |
| --- | --- | --- |
| G1 (primary) | Attacker values answered, SYSTEM2-FREE − NAIVE | WIN if the upper bound is below −1 point |
| G2 | Current holders, SYSTEM2-FREE − NAIVE | NON-INFERIOR if the lower bound is above −5 points |
| G3 | Never-streamed offices, SYSTEM2-FREE − untouched | NON-INFERIOR if the lower bound is above −5 points |
| G4 | Dated questions, SYSTEM2-FREE − NAIVE | WIN if the lower bound is above +1 point |
| G5 | What follows, SYSTEM2-FREE − NAIVE | WIN if the lower bound is above +1 point |
| G6 | GSM8K and MMLU, SYSTEM2-FREE − untouched | NON-INFERIOR if the lower bounds are above −3 and −2 points |

**Reported, not judged:**
- SYSTEM2-FREE − SYSTEM2 with the registry on attacker values, current holders, never-streamed offices, kept offices, dated questions and what follows: what the registry is worth;
- the gate's own model-free counts (attacker values ever held, current holders at the end).

## Predictions
- **G1 WIN.** RF-1's gate admitted no attacker value in 20 worlds, and on dev world 9792 none of 98 attacked offices. NAIVE answers attacker values (CCL-4 7B: SYSTEM2 − NAIVE −8.70).
- **G3 and G6 NON-INFERIOR**, by the scope rule.
- **G4 and G5 WIN**, as with the registry.
- **G2 NOT SHOWN, more likely than not.** With no registry, a value needs three established voices, so the gate is slow. On dev world 9792 it held the current holder of 45 of 53 clean changed offices at the end (85%), and RF-1 held 83%, against about 97% with the registry. NAIVE answers the latest report.
- The cost of having no registry is expected to show in current holders, not in lies.

## Validity
