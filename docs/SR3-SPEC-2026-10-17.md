# SR-3: the remaining rule-system mechanisms, and their mixes

**Status:** design, written on 17 October 2026 before any SR-3 code was run. SR-3 uses the same branch and folder as SR-1 and SR-2 and makes no model calls.

Coverage register items covered here:

- Mīmāṃsā viniyoga order
- the Pāṇinian conflict order
- Nyāya bādhita, meaning pratyakṣa over anumāna
- anupalabdhi, the knowledge of absence

SR-3 also tests two mixes of everything rule-based so far. The register also lists arthāpatti, the remaining hetvābhāsas and blocking saṃskāras. These need negative lessons or are already implicit in the learner, so they go to SR-4 (see §6).

## 1. Base and question

SR-2 showed that ordinary rule learning (R-ORD) is the strongest of the lesson learners. So each SR-3 mechanism is added on top of R-ORD and compared with R-ORD itself.

The question is whether a given śāstra rule makes a competent ordinary learner better on new data.

## 2. Mechanisms

### VIN: Mīmāṃsā viniyoga

Mīmāṃsā Sūtra 3.3.14: *śruti-liṅga-vākya-prakaraṇa-sthāna-samākhyānāṃ samavāye pāradaurbalyam arthaviprakarṣāt*. When the grounds conflict, each later ground is weaker than the one before, because it lies further from the meaning.

- **Śruti (direct statement).** When no validated lesson matches the case exactly, śruti is silent.
- **Liṅga (indicative mark).** Next, use the lessons that match all but one of their own conditions. If these near-matches agree, they decide.
- **The weaker grounds.** Otherwise, decide from experience, the shared 1-NN fallback.

### PAN: Pāṇinian conflict order

Pāṇini 1.4.2, *vipratiṣedhe paraṃ kāryam*, read through the paribhāṣā *pūrva-para-nitya-antaraṅga-apavādānām uttarottaraṃ balīyaḥ*.

When matched validated lessons conflict:

1. A strictly more specific lesson (apavāda) bars the more general one.
2. Any conflict that remains is decided by the later lesson (para), the most recently validated.

The ordinary rule is the largest support.

Nitya and antaraṅga concern the order in which rules apply during a derivation. A single classification has no such order, so neither is mapped.

### BAD: bādhita, pratyakṣa over anumāna

If an identical past case is in memory, with the same values and the same missing values, its label decides before any lesson does. The most recent such case wins.

A conclusion that a stronger pramāṇa contradicts is *bādhita*, and direct experience of the very same object outranks inference.

### ANU: anupalabdhi

A missing value becomes the observed value `?`. Lessons can then condition on it, and 1-NN can match it.

The ordinary policy, as in SR-1 and SR-2, is that a missing value never satisfies anything (asiddha). Non-apprehension of what would have been apprehended is itself knowledge of absence.

ANU changes nothing on datasets without missing values.

### MIX-ORD

R-ORD with VIN, PAN, BAD and ANU together.

### MIX-SH

SR-2's R-SHASTRA2 (upādhi, saṃśaya, apavāda carve-outs, satpratipakṣa and B/N/V) with VIN, PAN, BAD and ANU added.

When a conflict survives the apavāda bar:

1. If one lesson is decisively stronger (twice the support), it decides.
2. Otherwise, the later lesson decides.

## 3. Arms

There are 11 arms:

| Group | Arms |
| --- | --- |
| Non-lesson baselines | EXT-DT, EXT-NB, EXT-1NN |
| Lesson learners from SR-1/SR-2 | R-ORD, R-SHASTRA2 |

| Mixes | MIX-ORD, MIX-SH |

Every SR-1 and SR-2 arm must reproduce its earlier predictions byte for byte.

## 5. Hypotheses and decision rules

The rules are the same as SR-1 and SR-2. Δ is the dataset-averaged paired accuracy difference over 10 orders. The CI comes from a stratified bootstrap (10,000 resamples, seed 12345).

| Verdict | Condition |
| --- | --- |
| WIN | Δ ≥ +1.0 pp and the CI lower bound > 0 |
| NO WIN | CI upper bound < +1.0 pp |
| UNDETERMINED | anything else |

| Hypothesis | Comparison |
| --- | --- |
| **H1 (primary)** | MIX-ORD − R-ORD on the held-out data |
| H2 | R-ORD+VIN − R-ORD |
| H3 | R-ORD+PAN − R-ORD |
| H4 | R-ORD+BAD − R-ORD |
| H5 | R-ORD+ANU − R-ORD (also reported on the three datasets with missing values) |
| H6 | MIX-SH − R-ORD |
| H7 | MIX-SH − R-SHASTRA2 |

The run is INVALID if any of these hold:

- a run fails;
- a run is non-deterministic;
- the regression check fails;
- on held-out data, a mechanism's own counter stays at zero in its arm. The counters are the liṅga decisions, para decisions, pratyakṣa decisions, and the absent values seen.

## 6. Deferred, with reasons

- **Arthāpatti (postulation).** It needs lessons that exclude a label. SR-4 will add negative lessons.
- **Viruddha and asiddha.** Asiddha is already the default handling of missing values (ANU is its alternative). Viruddha (evidence for the opposite) cannot arise in a precision-1 learner: a lesson is revised at its first counterexample.
- **Blocking saṃskāra (YS 1.50).** It is implicit, because formation requires precision 1 on all memory, so a refuted lesson cannot re-form.
