# PL-1 spec: telling the model what is reported but not yet verified

**Status:** spec, 23 October 2026, about 14:15 IST, before any model was asked. Dev next; the preregistration is frozen after dev and before the main run.

## Why
MC-1 ran the whole layer end to end with no registry (`docs/MC1-RESULT-2026-10-21.md`). It kept every attacker's value out of four models' answers, at a cost: the models named the current holder 17.92 points less often than with a memory that believed the latest report. The cause is lag. A real change made late in the stream is not yet confirmed by independent sources, so memory still holds the previous holder.

The roadmap's next idea (`docs/ROADMAP-CL-2026-10-21.md`, 21 October, 21:55) is a line for what is reported but not yet verified. PL-1 measures what that line buys in current holders named, and what it costs in attackers' values named.

## Arms
The same stream, gate and memory as MC-1 (`cl/mc1.py`, unchanged), asked on 2026-10-19:
- **NAIVE:** the latest report of each office, stated as verified memory (MC-1's).
- **LAYER:** the layer's memory block (MC-1's).
- **PENDING:** the layer's memory block, plus at most one line for a value that is reported but not yet verified. The line appears when, since memory settled its value, independent established sources (the gate's own voices) report another value. It gives how many such sources report it and the date of the latest report. Its exact wording, and how many sources it needs, are set on dev.

## Worlds, questions and models
- **Dev:** MC-1's dev world (seed 0, 60 offices). **Main:** a new TM world (seed 8900, never generated before, 240 offices).
- MC-1's questions and wording: who holds the office (DIRECT); who held it before (PREVIOUS); whether the previous holder still holds it (STILL) and whether the current one does (STILLNOW); and, for offices with a derived line, its direct question.
- MC-1's four models: claude-opus-5-5, gpt-6.1-sol, gpt-4.1-base and llama-4-maverick.

## Measures (MC-1's)
- **Current holder named** (DIRECT right), over every sampled office.
- **Attacker's value named**, over the attacked offices.
- Previous holder right, and both "still in post?" questions right.

## Tests (to be fixed in the preregistration after dev)
- **Primary, coverage:** current holder named, PENDING − LAYER, averaged over models per office, with MC-1's bootstrap.
- **Safety:** attacker's value named, PENDING − LAYER. The line is safe only if the upper end of the interval stays below a margin fixed on dev.
- Descriptive: the gap that remains to NAIVE; previous holder and "still" answers; how often a line appears, and how often its value is a real change or an attacker's.

## Limits known now
- The attackers are MC-1's simulated ones. Colluders are established sources, so a line could carry their lies; that is what the safety test measures.
- What a model does with an unverified line depends on the model. The line informs; it does not decide.
