# J-1 preregistration: frozen before the main run

17 October 2026. Freezes J-1 as defined in the [spec](J1-SPEC-2026-10-17.md). It is frozen in the same commit as [SR-5's preregistration](SR5-PREREG-2026-10-17.md), because the two share one held-out pool. No learner has touched the pool before this commit.

- Code SHA-256: `9b54aeea6e278cc1720e590d4ea54aaaa5f344815af80abf08d780faa03e97b9`. This is the same code as the J-1 and SR-5 dev runs.
- Held-out pool: as in SR-5's preregistration. That is nine shuffled UCI datasets in orders 15000–15009, the Elec2, airlines and gas-drift streams as 10 windows each, and synthetic seeds 15000–15019.
- Run-level details are frozen as implemented in `shastra/maitri.py`:
  - the recent window is 20 cases;
  - an expert's recent accuracy is computed over the cases seen so far when fewer than 20 have been seen;
  - the median is taken over the five recent accuracies;
  - every expert observes every case, including case 0, which is not scored.

**Findings.**

- On shuffled data the fivefold grade behaves almost exactly like following the long-run leader, at −0.07 pp.
- Under synthetic drift and noise it is slightly better: +0.36 pp and +0.14 pp.
- Every chooser beats the lesson learner alone by 1–2 pp. Choosing among experts is itself a strong mix.

No bug was found, and nothing changed after the dev run.
