## What it shows
- **CN-1's rule holds in a trained model.** Choosing by how likely a value is to keep holding left the model naming a no-longer-true holder for 0.12% of offices, against 0.61% when the newest values went first and 1.78% at random. It also named the current holder more often: 37.87% against 33.25%.
- **The model-free count was a good guide when the trained set was rehearsed.** The model named 97% of the values in its weights, and its right and stale shares were within 1.2 and 0.06 points of CN-1's count.
- **Without rehearsal, the count does not hold** (dev, first try, in the spec). An adapter trained only on each consolidation's new values kept mostly the latest one: 9–10% right, against 35–39% counted.
  - Consolidating into the weights is therefore two decisions: what to train (this rule) and keeping what was trained (rehearsal).

## Limits
- **One model at 7B, one training recipe, one kind of fact** (office holders, a six-month cycle).
- **Invented names:** the model could answer only from training. That isolates what was trained; a model's own knowledge is outside the test.
- **Volume is counted in values trained per consolidation.** Rehearsal makes the training grow with the set held in the weights.
