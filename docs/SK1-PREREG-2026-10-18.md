## Rules fixed in the code

**Becoming latent.** When a validated lesson meets a counterexample, its conditions and conclusion are kept as a latent impression, and its ripening is empty. A latent impression decides nothing.

**Ripening.** Each later observed case that meets an impression's conditions ripens it if the case carries the impression's conclusion, and resets its ripening if not.

**Re-manifestation.**
- After R consecutive ripenings, the impression leaves the latent store and becomes a validated lesson again. R is 2 for SAMSKARA and 3 for SAMSKARA-R3.
- This does not happen if an active lesson with the same conditions exists. That is counted as "already active".

**INVALID conditions:**
- non-determinism;
- a crashed run;
- SAMSKARA never re-manifesting a lesson on RECUR.

## Runs before the freeze (exposed data)

### Dev run a: stopped

The first dev run used the spec's exposed streams: elec2, airlines and gasdrift; the PK-1 and PK-2 streams; and MX-4's two streams. The spec named nine streams; MX-4's two were added in the code before any run. The run was stopped after 96 minutes, unfinished, and left no record.

The cause was the news stream (58 features). There SAMSKARA's churn grows without bound. On news window 0, by case 750 (the probe stopped at 787 cases):

| Measure | SAMSKARA |
| --- | ---: |
| Lessons created | 79,522 |
| Latent impressions | 23,273 |
| Re-manifestations | 31,331 |
| Time | 188 s, and growing quadratically |

R-ORD runs the whole 1,000-case window in 1.8 s.

On news, almost every short lesson meets a counterexample within a few cases (R-ORD's accuracy there is 52.9%). It then ripens again two cases later, re-manifests, and is broken again. Every turn of this cycle adds lessons. The other streams take under a second each.

**Change before the freeze.** News is left out of the dev streams. This is the only code change after the spec. It touches the dev task list only; the mechanism and the main run are unchanged.

**Findings.**
- **It helps where lessons return.**
  - RECUR: +1.7.
  - Label noise: NOISE +1.1. Under noise, a sound lesson broken by a mislabelled case comes back.
  - Most real streams: Beijing +4.9, gesture +1.6, ldpa +1.3, elec2 +1.2 and airlines +1.2.
- **It hurts where a counterexample was a true exception:** EXC −1.2, UPA −0.9 and DRIFT −1.2. It also hurts on gasdrift (−2.8).
- **The lower bar does not help.** R = 3 is slightly better than R = 2 on RECUR, NOISE and DRIFT.
- **The churn is large everywhere.**
  - On UPA, SAMSKARA re-manifests 55,319 lessons over 45 runs of 400 cases.
  - Harmful lesson applications roughly double, for example DRIFT 13.2% → 21.0%.
  - Accuracy survives because most re-manifested lessons are right most of the time.
