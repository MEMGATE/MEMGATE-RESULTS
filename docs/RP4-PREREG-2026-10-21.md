## 1. Question
A coach X left club A and now coaches club B, and A has a new coach Y. A verified memory holds B's fact. Asked who coaches A:
- does a model still name X?
- does the line the gate can derive from B's fact, "X no longer holds the post of head coach of A", remove that stale answer, and at what cost?

## 2. Design (as in the spec)
**Pairs.** 222 pairs from the Wikidata snapshot (`pairs()`), one per club A, in a fixed shuffled order.
- Dev used the first 50.
- **Main uses the other 172**, never asked before.

**Questions.** Both carry RP-1's date and the instruction "Answer with the person's full name only, or 'unknown' if you do not know.":
- **LINKED:** "Who is the head coach of A?"
- **DIRECT-B:** "Who is the head coach of B?"

**Conditions,** with the memory in the system message:
- **NONE:** no memory.
- **GATED-B:** B's verified fact.
- **GATED-B+:** B's verified fact and the derived line.
- **GATED-A:** A's own verified fact.

**Models.** RP-1's six, at RP-1's settings:
- gpt-6.1-sol, gpt-6-astra, grok-4.7 and claude-opus-5-5 at their defaults;
- gpt-4.1-base at temperature 0;
- llama-4-maverick at its default.

That is 172 pairs × 2 kinds × 4 conditions = 1,376 questions per model, 8,256 in all.

**Scoring.** `outcome()` in `cl/rp4.py`, which reads the answer's first non-empty line:
- **UNKNOWN** if that line says "unknown";
- else **CURRENT** if it names Y (for LINKED) or X (for DIRECT-B);
- else **STALE** if it names X (for LINKED);
- else **OTHER**.

Names use the lab's name matcher with the name recogniser.

**Change since the dev run:** the scorer now reads only the first line. In dev it had read the whole answer. Four dev answers were "unknown" followed by an explanation that named X or Y, and the old reading scored them STALE or CURRENT.

## 4. Hypotheses and decision rules
**The statistic:** for each pair, the mean over usable models of the difference between two conditions' 0/1 outcomes. The estimate is the mean over pairs, in percentage points. Its 95% interval is a bootstrap over pairs: 10,000 resamples, seed 12345. Each model's own difference is reported beside it.

| Test | Comparison | Rule |
| --- | --- | --- |
| **H1 (primary)** | STALE on LINKED: GATED-B+ − GATED-B | **WIN** if the interval lies wholly below −1 pp and no usable model's difference is above 0; **NO WIN** if the interval's lower bound is above −1 pp; otherwise UNDETERMINED |
| H2 | STALE on LINKED: GATED-B − NONE | two-sided: **DECREASE** if the interval lies wholly below −1 pp; **INCREASE** if it lies wholly above +1 pp; otherwise NO DIFFERENCE SHOWN |
| H3 (guard) | CURRENT on DIRECT-B: GATED-B+ − GATED-B | **NON-INFERIOR** if the interval's lower bound is above −2 pp; **INFERIOR** if its upper bound is below −2 pp; otherwise NOT SHOWN |
| H4 (cost) | CURRENT on LINKED: GATED-B+ − GATED-B | two-sided, as H2 |

**Usable models and validity:**
- A model with more than 5% of its questions unanswered or refused is left out of the hypotheses. Its results are still reported.
- The run is **INVALID** if fewer than 4 models are usable.

**Descriptive, no verdict:**
- the shares of CURRENT, STALE, UNKNOWN and OTHER per model, kind and condition;
- of the pairs a model answers STALE under NONE, the share still STALE under each other condition.

**Models differ in dev:**
- Under GATED-B, claude-opus-5-5 named X on 2% of pairs, against 34% with no memory: it drew the inference itself.
- gpt-4.1-base named X more often with B's fact than without, 56% against 42%.
- The derived line took every model to 4% or below.
- The derived line also makes some models say "unknown" where they had named Y from their own knowledge. claude-opus-5-5's CURRENT fell from 30% to 16%; H4 measures this cost.
