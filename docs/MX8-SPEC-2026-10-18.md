# MX-8: the supervisor that also knows the locus (MX-5 × SL-2), on fresh body-sensor data

**Status:** design, written on 18 October 2026 before any MX-8 code. No model calls are made.

## 1. Question

Two findings replicated separately:
- **MX-5 and MX-7:** the supervisor (three-source agreement without guessing, dismissal, audits, resets, saṃskāra) beats the plain agreement network (+13.14, +9.68 pp net credence).
- **SL-1 and SL-2:** evidence has a locus. Naming the locus as a feature helped the lesson learner (+0.72, +6.10).

MX-8 asks whether they combine: does each spy do better when it also knows whose case it is?

In a multi-camera site, each camera would also know which site or line it is watching. The test uses fresh data where both sources and loci are natural: several body sensors on several people.

## 2. Arms

All arms use `shastra/mx5.py`'s `run_supervisor`, unchanged.

| Arm | Pieces | Each spy sees |
| --- | --- | --- |
| SPIES | none | its sensor's features |
| SPIES+LOCUS | none | its sensor's features and the person |
| SUPERVISOR | DISMISS, AUDIT, RESET, SAMSKARA | its sensor's features |
| **SUPERVISOR+LOCUS** | the same | its sensor's features and the person |

**How the person is given.**
- Each source carries its own copy of the person column, so a failing sensor garbles its own copy only.
- The failure is injected once, with MX-5's `fail_from` and the locus-carrying sources, from case 600. All four arms see the same failing data; the arms without the locus ignore the copies.

## 3. Data: Daily and Sports Activities (UCI 256), new to the lab

The dataset records 19 activities by 8 people, 60 five-second segments each, giving 9,120 segments. Five units were worn (torso, right arm, left arm, right leg, left leg), each with a 3-axis accelerometer, gyroscope and magnetometer at 25 Hz.

**Reading (fixed before the data are opened beyond their documentation).**
- **Cases.** A case is one segment.
- **The three sources.** These are the first unit of each kind in the file's order: torso (trunk), right arm (arm), right leg (leg). Each source has the mean and standard deviation of its 9 channels over the segment, which gives 18 features, plus its copy of the person.
- **Not used.** The left arm and left leg.
- **Storage.** The 170 MB archive is not stored. A derived table of segment features is stored with its builder.

**Orders.**
- 10 shuffled orders (seeds 50000–50009), cut to 1,000 cases.
- Numeric columns are binned by the H-1 rule. The person is a category, and the label is the activity.

**Dev.** There is no dev run: every piece is frozen code from MX-5 and SL-1. The table is checked by shape only.

## 4. Hypotheses and decision rules

The decision rules are as before.

| Hypothesis | Comparison (net credence) |
| --- | --- |
| **H1 (primary)** | SUPERVISOR+LOCUS − SUPERVISOR |
| H2 | SPIES+LOCUS − SPIES |
| H3 (replication) | SUPERVISOR − SPIES, MX-5's primary on a fourth setting |
| Descriptive | wrong answers given alone; dismissals of the failed sensor |

**INVALID if:**
- any run is non-deterministic or crashes;
- the supervisor never dismisses.
