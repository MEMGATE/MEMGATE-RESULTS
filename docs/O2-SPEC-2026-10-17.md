# O-2: categories on real domains. Does a documented grouping of features (Sāṃkhya/Vaiśeṣika-style ontology) help a learner?

**Status:** design, written on 17 October 2026 before any O-2 code. No model calls are made.

## 1. Question

O-1 showed that tattva-shaped group features help when the groups are correct (+11.07 pp), and that random groups of the same shape do not. That result was *by construction*: the synthetic concepts were defined over the groups.

The open question in the coverage register is whether a grouping that the **domain itself documents** gives a gain on real data, where nobody built the concept around the groups.

## 2. Mechanism

- **Groups.** For each dataset, the feature groups are taken from the dataset's own documentation, listed in §3. They are fixed before any learner runs.
- **Marked values.** A feature value is *marked* if:
  - for a numeric feature binned by the H-1 rule, it is in the top quartile (`q3`);
  - for any other feature, it differs from that feature's most common value in the whole dataset. That is the same label-free, whole-dataset convention the binning uses.
  - Missing values are never marked.
- **Group features.** For each group, a new feature counts the group's marked members in the case. If more than 10 distinct counts occur, the count is cut into quartiles by the same H-1 rule.

**Views.**

| View | Features |
| --- | --- |
| flat | the original features |
| onto | the original features plus one count feature per documented group |
| rand | the original features plus count features over a random partition with the same group sizes, drawn once per dataset with `random.Random(4242)` |

**Arms.** R-ORD, EXT-NB and EXT-DT, each on each view: nine arms.

## 3. Data

Five UCI datasets, new to the lab, with documented groups. Each runs in 10 orders (seeds 18000–18009) and is cut to 1,000 cases.

| Dataset | UCI id | Cases | Features | Classes | Documented groups |
| --- | ---: | ---: | ---: | ---: | --- |
| Breast cancer Wisconsin, diagnostic (WDBC) | 17 | 569 | 30 | 2 | 3 groups by statistic (mean, standard error, worst), 10 each: `wdbc.names` §7 |
| Ozone level, eight-hour (`eighthr.data`) | 172 | 2,534 | 72 | 2 | hourly wind speed WSR0–23 with peak and mean; hourly temperature T0–23 with peak and mean; the 850 hPa, 700 hPa and 500 hPa blocks; the remaining indices: `eighthr.names` |
