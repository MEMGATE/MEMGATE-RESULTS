# ML-2: Kālacakra layered recency for model-written lessons, and a replication of ML-1

**Status:** design, written on 17 October 2026 before any ML-2 code was run. Models: gpt-6-astra and gpt-6.1-sol, as in the ML-1 main run.

## 1. Question

ML-2 tests two things.

1. **Recency layers with a real model.** T-1's one symbolic win from the Kālacakra was layered recency retrieval: +1.04 pp overall and +3.66 pp under drift. Does the same layering help a language model when it is used to choose which past cases the model is shown, especially when the world's rules change?
2. **Replication.** Does ML-1's WIN for model-written lessons over retrieval-only (+3.84 pp) replicate on new seeds, and in a world with drift?

## 2. Design

**Lesson machinery.** Proposals, the shared proposal stream, ORD lesson management, prompts, parsing, budget and retries are all exactly as in ML-1.

**Worlds.**

- EXC and NOISE, as in ML-1.
- DRIFT: SR's DRIFT family generated with a 100-case stream, so the rules are redrawn at case 50.
- Seeds: dev 0 (exposed); main 12000–12005, never used.

**Two factors.**

- **Lessons:** none, or ORD lessons.
- **Neighbour retrieval:** plain (the 8 nearest by Hamming distance, ties to the most recent), or **kala**.

**Kala retrieval** proceeds as follows:

1. Let d\* be the best distance among all past cases.
2. Take, in order, the cases within d\* + 1 from the recent layer (the last 20 cases), then from the middle layer (21–60 back), then from the old layer. Within each layer, the nearest cases come first.
3. Fill any remaining slots with the plain nearest cases.

The layer sizes are scaled to the 100-case streams. T-1 used 30 and 180 for 730-case streams.

**Arms.**

| Arm | Lessons | Neighbours |
| --- | --- | --- |
| EXP | none | plain |
| ORD | ORD | plain |
| KALA-EXP | none | kala |
| KALA | ORD | kala |

## 3. Hypotheses and decision rules

The decision rules are as in ML-1: model × family strata, worlds as units.

| Hypothesis | Comparison | Strata |
| --- | --- | --- |
| **H1 (primary)** | KALA − ORD | DRIFT strata only |
| H2 | KALA − ORD | all strata |
| H3 (replication of ML-1) | ORD − EXP | all strata |
| H4 | KALA-EXP − EXP | all strata (layering without lessons) |

**INVALID conditions:**

- more than 5% of calls fail;
- kala retrieval never differs from plain retrieval.
