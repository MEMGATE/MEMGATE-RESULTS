# SL-1: same-locus evidence (Kiraṇa 6; Nyāya pakṣadharmatā)

**Status:** design, written on 18 October 2026 before any SL-1 code. No model calls are made.

## 1. Sources and mapping

**Kiraṇa, chapter 6.** Codex read it on its branch (`docs/SANATANA-KIRANA-CHAPTER6-2026-10-17.md`) from the GRETIL transcription based on Goodall 1998, which is not proofread. In the context of who is fit for initiation, the evidence must come from the same person: "smoke in one tree does not prove fire in another" (Codex's working interpretation).

**Nyāya.** An inference needs its reason to be a property of the subject (*pakṣadharmatā*). The Tarkasaṅgraha defines consideration (*parāmarśa*) as knowing the reason, qualified by pervasion, as present in the subject.

**The mapping (mine).** Cases come from loci: patients from hospitals, teams in a factory, monitoring stations.
- A lesson formed from all cases is a general pervasion.
- **SAME-LOCUS:** a lesson may decide a case from locus *s* only if at least one of its supporting cases comes from *s*, that is, if the pervasion has been seen to hold in that locus.
- When no lesson may decide, the fallback is the nearest stored case from the same locus, or the nearest overall if the locus has none yet.
- The locus is not a feature.

## 2. Arms

| Arm | Content |
| --- | --- |
| R-ORD | the locus dropped |
| R-ORD+LOCUS | the locus as an ordinary feature that lessons may name |
| **SAME-LOCUS** | the rule above |
| RANDOM-LOCUS | the same rule with the locus labels randomly permuted across cases, keeping each locus's size (`random.Random(seed + 666)`). It tests whether any grouping would do. |

## 3. Data

Three UCI datasets, new to the lab. Each runs in 10 orders (seeds 35000–35009), cut to 1,000 cases (all 617 for heart). Numeric columns are binned by the H-1 rule.

| Dataset | Loci | Cases | Label |
| --- | --- | ---: | --- |
| Heart disease, the three sites never used here: Hungary, Switzerland, VA Long Beach (UCI 45; Cleveland was used in SR-4 and is excluded) | 3 hospitals | 617 | disease present (num > 0) |
| Garment employees' productivity (UCI 597) | 12 teams | 1,197 | the team met its target (actual ≥ targeted productivity). The date is dropped; `actual_productivity` is dropped because it defines the label. |
| Beijing multi-site air quality (UCI 501), hourly, March 2013 to February 2017 | 12 stations | 420,768 | PM2.5 above 75 µg/m³, China's Grade II limit, applied to hourly values. Dropped: `No`, `year`, `day`, and `PM10`, which contains PM2.5. |

**Dev.** Exposed data with loci: PV-1's MiceProtein (mouse as the locus) and PK-2's activity of older people (the person file as the locus, shuffled), orders 2000–2009.

## 4. Hypotheses and decision rules

The decision rules are as before, stratified by dataset.

| Hypothesis | Comparison |
| --- | --- |
| **H1 (primary)** | SAME-LOCUS − R-ORD |
| H2 | SAME-LOCUS − RANDOM-LOCUS |
| H3 | SAME-LOCUS − R-ORD+LOCUS |
| Descriptive | per dataset; how often a lesson was silenced for want of local support |
