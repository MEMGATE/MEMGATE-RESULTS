## What this means

**Akhyāti works where it should, and nowhere else.** Prābhākara's account says an error is a failure to discriminate, not a false cognition. As a learning rule: a counterexample identical to a case the lesson already explained gives no ground for revision.

- **Where it helped:** on the three duplicate-rich datasets, where the same features meet different labels, keeping the lesson gained +0.6 to +3.3 pp.
- **Where it did nothing:** on datasets with no identical rows, the rule never fired and changed nothing.
- **Replication:** it was significant in both the dev run (+0.15) and the main run (+0.61).
- **Its weakness:** on the Elec2 stream in dev (−2.0 pp), an indiscernible contradiction was a real change, not noise.

Akhyāti now joins anupalabdhi as a small, repeatable gain on real data. Neither reaches the 1 pp margin.

**Pratyāhāra, withdrawing from features no lesson uses, does not help.** Early lessons use few features, so the fallback ignores features that still matter. It lost up to 1.1 pp on small or wide datasets (flags, optical digits), and gained only on Parkinsons and sonar.

**The best-so-far mix** (anupalabdhi + akhyāti + pratyāhāra) gave +0.46 pp and, for the first time, edged above naive Bayes on held-out data (+0.46 [+0.08, +0.85]). The gain comes from akhyāti; anupalabdhi had few missing values to act on in this pool.
