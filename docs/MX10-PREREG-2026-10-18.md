## Rules fixed in the code

- **The failure** starts at case 240 = int(0.6 × 400).
  - ONE uses MX-5's `fail_from`.
  - TWO uses MX-9's `fail_two` (`random.Random(f"MX9-FAIL2:{seed}")`).
- **The measure** is wrong answers given alone after case 240, per case after it, by the prefix method (full run less the run on the first 240 cases).
- **H1 (safety).** SAFE if the upper bound of the 95% bootstrap CI (10,000 resamples, seed 12345) of SUPERVISOR's measure in TWO is below 0.02. UNSAFE otherwise.
- **H2 and H3** use the usual WIN rule on net credence.

**INVALID conditions:**
- non-determinism;
- a crashed run;
- NOT TESTABLE, if SPIES's sound coverage is below 5%.
