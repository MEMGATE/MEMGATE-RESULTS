## Main run

Run once, from `claude_lab/`:

```
python -m shastra.run_sr2 main --prereg docs/SR2-PREREG-2026-10-17.md --out runs/sr2-main-20261017
```

Scope:

- 5 synthetic families × seeds 3000–3019.
- 6 held-out datasets × orders 4000–4009.
- 9 arms.
- The first instance of each group is repeated for the determinism check.

A completed run is never re-run or overwritten.

## Decision rules (unchanged from SR-2 spec §5)

**H1 (primary): R-SHASTRA2 − R-ORD on the six held-out datasets.**

| Verdict | Condition |
| --- | --- |
| WIN | Δ ≥ +1.0 pp and CI lower bound > 0 |
| NO WIN | CI upper bound < +1.0 pp |
| UNDETERMINED | otherwise |
| INVALID | any of: a failed run, non-determinism, or B, N or V never executing on held-out data |

**H2: R-SHASTRA2 − R-SHASTRA.** Same rules as H1.

**H3 (descriptive):** comparisons against EXT-DT, EXT-NB and EXT-1NN, plus the ablations.
