# H-1: the winning mechanisms combined, on six new real datasets

**Status:** design, written on 17 October 2026 before any H-1 code was run. No model calls.

## 1. Question

Four symbolic mechanisms have earned a place so far:

| Mechanism | Experiment | Result |
| --- | --- | --- |
| Kālacakra-style layered recency fallback (KALA) | T-1 | +1.04 pp WIN; +3.66 under drift |
| Anupalabdhi, a missing value treated as observed absence (ANU) | SR-3 | +0.34 pp, significant but below the margin |
| The śāstra policy's noise tolerance (R-SHASTRA2) | SR-1/SR-2 | +0.8 to +1.8 pp on the NOISE family |
| Indra's Net-checked transfer | A-1 | +2.40 pp, but it applies only when moving between worlds, so it is not part of a single-dataset test |

**Question:** do the applicable winners, combined, beat ordinary rule learning on six real datasets that no experiment has used?

## 3. Data

### Held out

Six UCI datasets (CC BY 4.0), none used before. Each runs in 10 orders (seeds 13000–13009), cut to 1,000 cases.

| Dataset | Cases | Features | Classes | Missing values | Note |
| --- | ---: | ---: | ---: | --- | --- |
| Credit approval (crx) | 690 | 15 | 2 | yes | |
| Hepatitis | 155 | 19 | 2 | yes | |
| Annealing | 898 | 38 | — | yes | `.data` and `.test` concatenated |
| Dermatology | 366 | 34 | 6 | yes (age) | |
| Horse colic | 368 | 21 | 3 | yes | `.data` and `.test` concatenated; see note |
| Contraceptive method choice | 1,473 | 9 | 3 | no | |

**Horse colic.** The label is attribute 23, "outcome" (lived / died / euthanised). The features are attributes 1–22 without the hospital number, which is an identifier. Rows with a missing outcome are dropped.

### Numeric columns, rule fixed now

A column counts as numeric if every non-missing value parses as a number and it has more than 10 distinct values. Each numeric column is cut into four equal-frequency bins, `q0`–`q3`, at the 25th, 50th and 75th percentiles of all its non-missing values in the dataset. The labels are not used to choose the cuts. All other columns stay categorical.

### Synthetic

The five SR families with new seeds 13000–13019.
