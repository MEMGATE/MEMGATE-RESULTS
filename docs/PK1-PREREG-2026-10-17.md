## Rules fixed in the code

**The health check.**
- W = 30 and three standard errors, with the floor max(prakṛti, 0.05).
- Prakṛti is the error rate since the last treatment, leaving out the latest W scored cases. At least 2W scored cases are needed since the last treatment.

**Śodhana.** It dissolves every active lesson that decided wrongly among the latest W cases, or descends by revision from one that did. The case memory is kept.

**Reset.** It rebuilds the learner from the latest W cases.

**The matched control.** RANDOM-SODHANA applies as many treatments as PRAKRTI had in that run, at cases from 2W on, drawn by `random.Random(seed + 333)`. The seed is the window index for streams and the world seed for synthetic worlds.

**INVALID conditions:**
- any non-determinism in the repeats;
- a failed run;
- PRAKRTI never treating on the streams.

## Dev runs (exposed data)

The dev runs used the SR-5 streams (elec2, airlines, gasdrift; 10 windows each) and the synthetic dev seeds.

**Dev run a** is in [`runs/pk1-dev-20261017-a`](../runs/pk1-dev-20261017-a/SUMMARY.md).
- As first written, śodhana dissolved only the erring lessons. That was vacuous: PRAKRTI equalled R-ORD exactly everywhere, although it treated 1 to 4 times per window.
- The reason: R-ORD supersedes a lesson at its first counterexample and keeps a narrowed revision of it. The vitiated knowledge lives on in that revision.
- The rule was therefore amended to dissolve the revisions too. The spec was amended, and run a is kept as the record.

**Dev run b** is in [`runs/pk1-dev-20261017-b`](../runs/pk1-dev-20261017-b/SUMMARY.md). It used the amended code: 255 runs, all 8 repeats identical, nothing failed.

**Findings.**
- **The health check fires where it should.**
  - About once per DRIFT world, at the switch.
  - Almost never on stable worlds: none on EXC, DNF and UPA, and 0.1 per world on NOISE.
  - 1 to 4 times per window on the real streams.
- **Targeted śodhana is weak.** Even with revisions included, it adds only +0.42 pp on DRIFT and ≈ 0 on the streams. The vitiated knowledge is not only in the lessons that failed: the case memory and the untouched lessons still carry the old world.
- **The full reset at the same moments is strong under a real switch:** +10.59 pp on DRIFT. On the exposed streams it is +0.09: +1.3 on elec2, −0.6 on airlines.
- **Neither costs anything on stable worlds,** because the check almost never fires there.

No other change was made after dev run b.
