# ML-6 preregistration: frozen before the main run

18 October 2026. This freezes ML-6 as defined in the [spec](ML6-SPEC-2026-10-18.md), including the 10-case warm-up added after the smoke run.

- Code SHA-256: `c736ab051d05a6a86ca3240f1fd33d38943610786ed2c41a5550aa64af21f646`. It is the same code as the dev run (commit `e19dbfa8`). Later commits changed only documents.
- Model: gpt-6.1-sol, through the same route as ML-4 and ML-5.
- Main worlds: synthetic EXC, NOISE and DRIFT at the new seeds 38000–38005, 100 cases each. That gives 18 worlds and about 8,600 calls.

## Rules fixed in the code

**Warm-up.** Every arm observes the first 10 cases.

**MIX-JIJNASA.** After the warm-up, the members observe a case when they disagree or one gives no answer.

**MIX-RANDOM-ASK.** Its remaining budget is drawn from the cases after the warm-up by `random.Random(seed + 777)`.

**H2.** It compares MIX-FULL's accuracy on the cases where all three members agree with as many random cases, drawn by `random.Random(seed + 999)`. A world with no unanimous case counts 0.

**INVALID conditions:**
- model failures plus refusals above 2% of calls;
- unparseable answers above 2%;
- a crashed world.

## Runs before the freeze (exposed seeds)

**Smoke run.** It is in [`runs/ml6-smoke-20261018-a`](../runs/ml6-smoke-20261018-a/SUMMARY.md). Without a warm-up, the assembly was of one mind after the first case and never asked again. This led to the warm-up.

**Dev run.** It is in [`runs/ml6-dev-20261018-a`](../runs/ml6-dev-20261018-a/SUMMARY.md): seed 0 of each family, 1,434 calls, 0 failures, 0 refusals, 0 unparseable answers.

| Family | MIX-FULL | MIX-JIJNASA | MIX-RANDOM-ASK | Labels asked | Of one mind |
| --- | ---: | ---: | ---: | ---: | ---: |
| EXC | 90.9 | 92.9 | 83.8 | 30% | 79% |
| NOISE | 80.8 | 75.8 | 69.7 | 34% | 70% |
| DRIFT | 69.7 | 62.6 | 65.7 | 53% | 55% |

| Comparison | pp |
| --- | --- |
| H1: MIX-JIJNASA − MIX-RANDOM-ASK | +4.04 |
| H2: of one mind − random | +4.82 |
| MIX-JIJNASA − MIX-FULL | −3.37 |

Each family has a single world, so these intervals are degenerate.

**Findings.**
- **With a language model as a member, asking under doubt beat random asking** on EXC (+9.1 pp) and NOISE (+6.1).
- **It lost on DRIFT** (−3.1). After the switch, the members agreed on the old rule and did not ask: MX-3's blind spot, here without audits.

No other change was made after the smoke run.
