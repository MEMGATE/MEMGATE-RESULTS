# SE-1 preregistration: frozen before the main run

18 October 2026. This freezes SE-1 as defined in the [spec](SE1-SPEC-2026-10-18.md), including its amendment (the gated stream).

- Code SHA-256: `48858dde62bf846dfd0e4188fe7d2cac20a16adaa2e334acb52d0eb50e428387`. It covers `cl/se1_world.py` and `cl/se1_modal.py`, line endings normalised. It is the code of dev run b (commit `aceff40b`).
- **Model.** `Qwen/Qwen2.5-0.5B-Instruct`, revision `7ae557604adf67be50417f59c2c2f167def9a775`, on one Modal A10G per task.
- **Main worlds.** Seeds 1000–1007: eight new worlds, five arms each, which gives 40 tasks plus one repeat.

## Rules fixed in the code

**Training.**
- LoRA r = 16, α = 32, dropout 0.05, on all attention and MLP projections.
- AdamW, learning rate 2e-4, batch 16, 6 epochs per session.
- Loss on the answer tokens only. Two question phrasings per fact.

**Arms.**
- NAIVE trains on every report of the session.
- GATED-NOCHECK and GATED train on the gated stream: the session's reports whose value equals the gate's admitted value.
- GATED adds the constitution check:
  - after training, if core retention falls below 98%, roll back;
  - retrain with the core items replayed to half of the data;
  - if it still regresses, skip the session.
- CONTEXT trains nothing, and gives every admitted fact in the system prompt.

**The gate.**
- Registry values are admitted, and a newer one sublates an older one.
- Testimony is admitted when at least two trusted sources' latest claims agree.
- A source is dismissed when at least 20% of at least 5 same-session checkable claims contradict the registry.

**Scoring.** Greedy decoding of at most 12 new tokens. A name or number is right when the normalised output contains it. The core suite is the first 100 pool questions the frozen model answers correctly.

**Decisions.** A bootstrap over the 8 seeds, 10,000 resamples, seed 12345:
- **H1:** WIN if poison falls by ≥ 1 pp and the CI's upper bound is below 0;
- **H2, H4, H5:** the usual WIN rule;
- **H3:** NON-INFERIOR if the CI's lower bound is above −5 pp.

**INVALID conditions:**
- a failed task;
- FROZEN truth above 10%;
- NAIVE truth below 30%.

## Runs before the freeze (exposed seeds 0–3)

**Smoke** (seed 0, NAIVE). Truth 94.2%, poison 16.7%, retention 85%, 93 s.

**Dev run a** ([`runs/se1-dev-20261018-a`](../runs/se1-dev-20261018-a/SUMMARY.md)). The gated arms trained each admitted fact only once and learned little: GATED truth 15% against NAIVE's 92%. This led to the amendment.

**Dev run b** ([`runs/se1-dev-20261018-b`](../runs/se1-dev-20261018-b/SUMMARY.md)). 20 tasks, 25 GPU-minutes, about $0.46.

| Arm | Truth | Poison | Update (new) | Retention |
| --- | ---: | ---: | ---: | ---: |
| NAIVE | 92.1 | 25.0 | 91.7 | 88.8 |
| GATED-NOCHECK | 95.4 | 0.0 | 97.9 | 90.8 |
| GATED | 95.2 | 0.0 | 85.4 | 99.5 |
| CONTEXT | 26.0 | 0.0 | 22.9 | 65.8 |

| Hypothesis | Dev result (pp) |
| --- | --- |
| H1 | −25.00 |
| H2 | +10.75 |
| H3 | +3.12 |
| H4 | −6.25 |
| H5 | +8.75 |

The repeat of seed 0 GATED gave identical metrics.

**What the dev runs show.**
- The gate admits no poison.
- Learning only the gated stream gives *more* truth than learning everything.
- The constitution check keeps almost all core ability. It also slows updates a little, because its rollback and replay hold the weights back.
- A 0.5B model cannot use 117 facts given in its prompt (CONTEXT 26%), and the long prompt costs it core ability.
