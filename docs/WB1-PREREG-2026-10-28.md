## Why
A lab will say: "your tests are your own." WikiBigEdit (Thede, Roth, Bethge, Akata and Hartvigsen, ICML 2025; Apache-2.0) is a public benchmark of real Wikidata changes, February to July 2024. It has published results for knowledge editors, retrieval and continual fine-tuning. Its files were downloaded on 28 October without an account (`D:/pramana-agi/ext/wikibigedit`; their SHA-256 are recorded in each run's manifest).

## The benchmark as used here
**The data.** Each change has:
- a question and its answer;
- a rephrased question and a persona-styled one (generalization);
- a locality question about a nearby, unrelated fact, with its answer;
- sometimes a two-step question (multi-hop).

**The stream.** Eight sessions, one per interval of the benchmark. From each interval a fixed draw of changes is taken (`cl/wb1.py select`). A change is usable when:
- it is tagged new or update;
- every field is present;
- its answer is at most 40 characters and is not written in its own question;
- it is the only change kept for its subject and relation.

**The worlds.** World 9726 takes the first 250 of each interval's shuffled draw, world 9727 the next 250, and the dev world 9792 its own changes after those 500. No two worlds share a change. A main world has 2,000 changes.

**What counts as right.** An answer is right when it contains the expected answer as whole words (lower case, accents and punctuation removed).

## The system under test
CCL-7's learner, as far as it applies to facts from one reliable source (Wikidata). Each session it:
- trains the session's changes;
- rehearses everything learned before (a change's newer answer replaces its older one);
- rehearses the untouched model's own answers to CCL-7's anchors (the chosen version, taken from a CCL-7 main run of the same model);
- checks itself and practises what it misses (CCL-7's self-test and practice, of fixed size).

What is not used:
- The gate, the registry questions, the dated and what-follows rows, and the period and neighbour rows are for offices.
- The scope rule is not used either. Every question goes to the trained weights, so what is measured is the weights alone.

The kernel is CCL-7's, copied unchanged from the run that gives the anchors.

## Arms
- **SYSTEM:** the learner.
- **NAIVE:** fine-tuning on each session's changes only.
- **FROZEN:** the untouched model.

Retrieval is not run here. The package cites the benchmark's own published numbers for retrieval and editors as context, on their models, not ours.

## Hypotheses
All are after session 8, the two worlds pooled, with a paired bootstrap over items within each world (`ccl1.boot`; 10,000 resamples, seed 12345, 95% percentile intervals).

| H | Measure | A − B | Rule |
| --- | --- | --- | --- |
| W1 | The questions of changes from sessions 1–4 (kept to the end) | SYSTEM − NAIVE | WIN if the lower bound is above +1 point |
| W2 | The questions of every change | SYSTEM − NAIVE | WIN, above +1 |
| W3 | Rephrased questions | SYSTEM − NAIVE | WIN, above +1 |
| W4 | Persona-styled questions | SYSTEM − NAIVE | WIN, above +1 |
| W5 | The questions of every change | SYSTEM − FROZEN | WIN, above +1 |
| W6 | Locality questions | SYSTEM − FROZEN | NON-INFERIOR, above −5 |
| W7 | GSM8K (150) | SYSTEM − FROZEN | NON-INFERIOR, above −3 |
| W8 | MMLU (200) | SYSTEM − FROZEN | NON-INFERIOR, above −2 |
| W9 | XSTest's unsafe prompts refused | SYSTEM − FROZEN | NON-INFERIOR, above −5 |
| W10 | IFEval, strict (200) | SYSTEM − FROZEN | NON-INFERIOR, above −5 |

The margins for W7–W10 are CCL-6's for the weights alone.

## Validity
A world is valid if:
- both arms finished 8 sessions with the done line;
- FROZEN, NAIVE and SYSTEM answered every question.

A run stopped by the machine without output is rerun once, in a new folder.
