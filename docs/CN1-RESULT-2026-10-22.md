## What it shows
- **What fine-tuning on the latest updates puts into the weights is the most likely to reverse.** 7.05% of the values it trained stopped holding within six months. When the layer's freshness estimate chose instead, 1.11% did, about one sixth as many, and close to the bound of 0%.
- **Fewer stale values in the weights, and no loss of coverage.** At the same training volume, the weights held a no-longer-true value for 0.12% of offices, against 1.79% for random choice and 0.67% for newest-first. They also held the current holder for more offices (39.01% against 34.10%).
- **A rule for the hybrid design.** Volatile values stay in memory, where a change is one line and removal is exact. Values likely to keep holding go into the weights, where a reversal costs a rollback.
  - CH-1's dev points the same way: facts in memory compose with what the model knows; facts newly trained into the weights did not, in short answers.
- **Simple stability rules are not enough.** Training the longest-held values first reversed rarely (1.59%), but left stale values in the weights for 1.61% of offices. When a long-held value did change, its replacement was new, so this rule moved it last.

## Limits
- **Model-free:** this counts what each rule puts into the weights, not what a trained model answers.
- **One kind of fact:** office holders, on a six-month cycle. Other facts change at other rates.
- **Volume is counted in values trained, not GPU time.**
