## What it shows
- **Discovery against reuse, measured.** The agents found working pandas 3 replacements by exploring the installed library: looking names up, running code, and keeping only what passed. Given those skills on programs they had not seen, they passed about a third more programs, in fewer steps.
- **Their own finds came close to a complete library.** The gap to SK-1's full verified library was 3.75 points, an interval that includes zero.
- **Only verified finds are kept.** A skill enters the library only when its program passed and every name it uses exists in the current release, the same check as SK-1's library. This is what keeps an agent's mistakes out of what it reuses.

## Limits
- **One kind of skill** (API migration), one library and two models. Discovery and reuse used the same tools.
- **Two other models were left out after dev,** because they could not show reuse: one passed everything with tools alone (the ceiling), the other passed little even with the full library (the floor).
- **The checks are execution and the release's names, not a person.** A wrong recipe that happens to run could be kept.
