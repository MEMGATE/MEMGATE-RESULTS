# AU-1 spec and preregistration: what the gate adds beyond the registry, against simpler rules at the same budget and against attackers who adapt to it

**Status:** frozen 20 October 2026, after a dev run on worlds 8390–8392. The main worlds, 8300–8319, have never been run.

## Why
A reviewer will ask whether "0 poison" means the gate simply asked the answer key. In TM-1 it asks the registry about 3,600 times per world, for 1,341 offices, and the registry is also the truth the scores use.

AU-1 holds the registry and its budget fixed and changes only the rule that decides what to believe:
- What does the gate add over using the registry alone?
- What does it add over standard ways of combining sources (majority vote, truth discovery) that get the same registry answers?
- Do attackers who adapt to its known rules get through?

## Worlds
- **Base:** TM-1's world (`cl/tm1_world.py`). It has 1,341 real offices with their 2024–2026 timelines, 12 sessions, the registry, four honest sources one session late after a change, and all TM-1 attackers: the stealthy poisoner, colluders, sleepers and sybil swarms.
- **Added attackers** (`cl/au1_world.py`), each with its own targets among the dark facts no other attacker targets: 5% of the facts, capped at half of those free dark facts.
  - **Threshold-liar pair T1 and T2:**
    - each reports like an honest source;
    - both report the same false values on a shared draw of their targets;
    - their lies are kept at about 13% of their claims, under the gate's 20% dismissal rate.
  - **Trust farmers F1 and F2:**
    - 40 true reports a session on non-dark facts, to earn a track record;
    - from session 6, false values on all their targets, every session.
  - **Budget exhausters X1, X2 and X3:** from session 2, all three report a past holder for 2 × the budget's number of changed facts each session. Stale values count as lag, not lies, so they are never dismissed; but each raises doubt and spends questions.
- **Main:** 20 worlds, seeds 8300–8319. **Dev:** seeds 8390–8392, already run.

## Arms (`cl/au1.py`)
Every arm sees the same reports.

| Arm | Rule |
| --- | --- |
| **NAIVE** | Last write wins over every report. |
| **REGISTRY-ONLY** | The registry's values only: its unasked reports, plus questions at the gate's budget. The questions go to the facts whose reports this session contradict its memory, most contradictions first. |
| **MAJORITY** | The registry's values as REGISTRY-ONLY gets them. Any other reported fact takes the value most sources reported this session, if one value leads. |
| **TRUTH-DISCOVERY** | The registry's values as REGISTRY-ONLY gets them. Other facts take the most likely value from each source's latest claim, with source reliability estimated iteratively (TruthFinder-style, prior 0.8, 5 rounds; the registry's values count as known truth). A value needs at least half the probability. |
| **GATE** | The memgate gate (`memgate/gate.py`), TM-1's settings. |
| **GATE-v2** | The candidate staleness rule (`cl/gate_v2.py`): settled = 2, stale_max = 3, stale_rate = 0.1. |

**Budget:** every registry-using arm gets TM-1's per-session budget, 303 questions (40 per 177 facts).

## Measures (per world)
- **poison_ever:** the attacker values an arm held at the end of any session, in % of facts. This is what a learner that trains on each session's memory would have trained on.
- **poison_end:** the attacker values held after the last session, in % of facts.
- **coverage_mean:** the share of changed facts whose held value is the holder of the session, averaged over the 12 sessions. **coverage_end** is the same after the last session.
- **Also:** stale_end (past holders held at the end); registry questions; honest sources (A, B, C, E) dismissed.

## Hypotheses

Intervals are world-level 95% t intervals over the 20 main worlds.

| | Comparison | Rule |
| --- | --- | --- |
| **H1 (primary)** | coverage_mean, GATE − REGISTRY-ONLY | WIN if the interval lies wholly above +1 pp and every world is above 0 |
| **H2a** | poison_ever, GATE − MAJORITY | WIN if the interval lies wholly below −1 pp and every world is below 0 |
| **H2b** | poison_ever, GATE − TRUTH-DISCOVERY | WIN if the interval lies wholly below −1 pp and every world is below 0 |
| **H3** | coverage_mean, GATE-v2 − GATE | WIN if the interval lies wholly above +1 pp and every world is above 0, and poison_ever GATE-v2 − GATE has an interval upper bound below +0.5 pp |

**Descriptive:**
- GATE − TRUTH-DISCOVERY on coverage_mean, coverage_end and stale_end;
- poison by attacker group for every arm;
- honest sources dismissed;
- registry questions used.

**What this cannot show.**
- AU-1 is model-free: it measures what each rule would put into memory or a training stream, not what a model then answers.
- The registry is the truth by construction.
- The sources and attackers are simulated, and only the offices and their timelines are real.

## Dev run (worlds 8390–8392)

Command: `python cl/au1.py run 8390 8391 8392 --out runs/au1-dev-20261020.jsonl`. Means are over the three worlds.

| Arm | poison_ever | poison_end | coverage_mean | coverage_end | stale_end |
| --- | ---: | ---: | ---: | ---: | ---: |
| NAIVE | 47.87 | 6.14 | 62.03 | 61.55 | 413.0 |
| REGISTRY-ONLY | 0.00 | 0.00 | 66.23 | 80.52 | 244.7 |
| MAJORITY | 7.90 | 0.10 | 78.02 | 81.19 | 240.0 |
| TRUTH-DISCOVERY | 2.91 | 0.00 | 78.49 | 81.06 | 227.0 |
| GATE | 0.52 | 0.00 | 77.22 | 87.74 | 155.7 |
| GATE-v2 | 0.52 | 0.00 | 82.10 | 97.00 | 38.0 |

- **Comparisons:**
  - H1: +10.99 [+10.25, +11.73].
  - H2a: −7.38 [−9.49, −5.28].
  - H2b: −2.39 [−4.35, −0.43].
  - H3: +4.88 [+4.21, +5.55], with poison_ever 0.00.
- **Gate against truth discovery:**
  - coverage_mean −1.28 [−2.60, +0.04];
  - coverage_end +6.68;
  - stale_end −71.
- **Attackers:**
  - Every attacker value either gate ever held came from sleepers, which the gate dismisses once caught.
  - No threshold-liar, farmer or exhauster value was held at the end of any session by either gate.
  - Truth discovery held threshold-liar values in all three worlds, and majority vote held farmer values too.
- **Dismissals:** no arm dismissed an honest source.

## Predictions
| Hypothesis | Prediction |
| --- | --- |
| H1 | WIN |
| H2a | WIN |
| H2b | WIN, less certain: one dev world was at −1.49 pp |
| H3 | WIN |

Truth discovery is expected to match the gate on coverage_mean (the gate within about 2 pp below it). It is expected to hold more stale values and to train on more attacker values.
