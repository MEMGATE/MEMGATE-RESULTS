## Rules fixed in the code

**Eligible columns.** Unbinned columns with more than 4 distinct present values in the stream.

**GANA.**
- The appended feature is the label most frequent among the observed cases with that value, with ties to the label seen first.
- It is shown only after 5 observed cases with the value, and is computed before the case's label.

**GANA-RANDOM.**
- The appended feature is a group drawn at the value's first sight (one of as many as there are classes, `random.Random(seed + 2727)`).
- It is shown under the same 5-case condition. This clarifies the spec, which did not say whether the condition applied to the control.

**The learner.** R-ORD on the rows with the appended features.

**INVALID conditions:**
- non-determinism;
- a crashed run;
- no gaṇa column in any dataset.

## Dev run a (exposed data)

It is in [`runs/pn2-dev-20261018-a`](../runs/pn2-dev-20261018-a/SUMMARY.md): adult, bank, amazon, click, speeddating and autos, in orders 2000–2009; 60 runs in 51 s.

| Comparison | pp |
| --- | --- |
| H1: GANA − R-ORD | −0.38 [−0.58, −0.20] |
| H2: GANA − GANA-RANDOM | −0.28 [−0.52, −0.03] |

**Findings.**
- **Gaṇa lessons do form.** Adult has 35 validated lessons per run using a gaṇa. They do not help, and the worst case is autos (−2.1).
- **They come too late.** R-ORD forms a lesson on a single value after 3 supports, and the gaṇa appears only after 5. By then, a value whose label is pure already has its own lesson. A value whose label is mixed gives an impure gaṇa as well. This was not foreseen in the spec.
