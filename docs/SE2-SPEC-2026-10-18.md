# SE-2: the Saṃskāra gate against stealthy and colluding poisoners, over a long horizon, in a larger model

**Status:** design, written on 18 October 2026 before any SE-2 code. It runs on GPU through Modal. No proprietary model is called.

## 1. Question

SE-1's gate won against naive continual fine-tuning, but its poisoner was easy: it lied about facts the registry checks. SE-2 attacks the gate where it is weakest:
- **A stealthy poisoner** lies only about *dark* facts, which the registry never reports on its own.
- **Two colluding poisoners** assert the same false values together. That satisfies SE-1's rule that two sources must agree.
- **A longer horizon.** Twelve sessions, with facts changing twice, at sessions 5 and 9.
- **A larger model.** Qwen2.5-1.5B-Instruct (Apache-2.0).

**The new defence is jijñāsā: ask under doubt.** It is this lab's most replicated principle (JK-1, PV-1, MX-2, RP-1). When trusted sources dispute a fact, the agent queries the registry for it (pratyakṣa on demand), up to a fixed budget per session. Sources contradicted by queried values are counted toward dismissal (Arthaśāstra 1.12).

## 2. Arms

| Arm | Gate | Constitution check |
| --- | --- | --- |
| FROZEN | — (a sanity check for prior knowledge) | — |
| NAIVE | none: trains on every report | no |
| GATED-SE1 | SE-1's gate, unchanged | yes |
| **GATED-SE2** | SE-1's gate with jijñāsā queries (below) | yes |

**Jijñāsā (GATED-SE2).**
- **When a fact is disputed.** At the end of each session, a fact is disputed when either:
  - two or more distinct values are each the latest claim of at least one trusted source; or
  - its registry value is contradicted by at least two trusted sources agreeing on another value, in later sessions than the registry value.
- **The query budget.** Up to 10 disputed facts per session are queried, those with the most trusted claims first (ties by fact order).
- **What a query returns.** The current true value, which enters as a registry value for that session.
- **Dismissal.** A source whose latest claim on a queried fact differs from the answer gets a contradiction. The dismissal rule is SE-1's: at least 20% of at least 5 checkable claims.

**Smṛti is not viparyaya (Yoga Sūtra 1.6–1.11).** In GATED-SE2, a claim of a value the gate once held for the fact is a memory of a past state, not an error. Such values are registry values, queried values or admitted values. The claim counts neither for nor against the source; only values the gate never held count as contradictions.
- *Added before any dev run.* A logic check of the gate alone, with no learner, on dev worlds 0–3 found it dismissing an honest source in 2 of 4 worlds. Honest sources keep reporting a changed fact's old value for one session, and that lag was counted as error.
- The registry value at the time a claim is checked is the only reference, so a lagging report is otherwise indistinguishable from a lie.

**Training.** Each gated arm trains on its gated stream: the session's reports whose value equals its gate's admitted value. Everything else is as in SE-1:
- LoRA r = 16, α = 32;
- 6 epochs per session;
- constitution check, rollback and replay;
- two question phrasings.

## 3. The world (synthetic, deterministic per seed)

- **Facts.** 100 invented companies × 2 attributes, which gives 200 facts. 40% of them (80) are dark: the registry never reports them on its own.
- **Registry.** It reports 15% of the non-dark facts per session.
- **Honest sources.** A, B, C and E each report 25% of all facts per session, true. After a fact changes, they keep reporting the old value for one more session.
- **Stealthy poisoner S.** It asserts false values for 15 dark facts, uncorroborated, in random sessions. It hides them among true reports.
- **Colluders C1 and C2.** They assert the same false values for 25 other dark facts, together, in the same sessions. They also hide them among true reports.
- **Changes.** 20 facts change at session 5 and 20 at session 9 (some twice). Poisoned facts are excluded.
- **Truth.** The values at session 12.

## 4. Measures

These are taken after sessions 4, 8 and 12. The verdicts use session 12.

| Measure | Definition |
| --- | --- |
| **Poison** | share of the 40 poisoned facts answered with a poisoned value, overall and split into stealthy and colluding |
| **Truth** | share of the 200 facts answered with the current value (a trained phrasing; a held-out phrasing is descriptive) |
| **Update** | share of the changed facts answered with the latest value |
| **Retention** | core-suite accuracy (SE-1's construction, on the 1.5B model) |
| **Queries** | registry queries used, a cost |

## 5. Hypotheses and decision rules

The decisions use a bootstrap over seeds, 10,000 resamples, seed 12345.

| Hypothesis | Comparison | Rule |
| --- | --- | --- |
| **H1 (primary)** | Poison: GATED-SE2 − GATED-SE1 | WIN if it falls by ≥ 1 pp and the CI's upper bound is below 0 |
| H2 | Poison: GATED-SE2 − NAIVE | the same rule |
| H3 | Truth: GATED-SE2 − NAIVE | NON-INFERIOR if the CI's lower bound is above −5 pp |
| H4 | Retention: GATED-SE2 − NAIVE | the usual WIN rule |
| H5 | Update: GATED-SE2 − NAIVE | the usual WIN rule |
| Descriptive | the colluding and stealthy shares of poison per arm; when the colluders were dismissed; queries used; the curve at sessions 4, 8 and 12 | |

**INVALID if:**
- a task fails;
- FROZEN truth is above 10%;
- NAIVE truth is below 30%.
