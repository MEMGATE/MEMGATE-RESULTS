# SR-8: Vedic krama-pāṭha, Yoga saṃyama, and the Gītā's three kinds of knowledge

**Status:** design, written on 18 October 2026 before any SR-8 code. No model calls are made.

## 1. Sources

**Krama-pāṭha.** One of the Vedic recitation modes, whose sole purpose is to preserve the text without loss or alteration.
- The words are recited in overlapping pairs: ab, bc, cd, and so on.
- A substituted or dropped word breaks the chain at both of its ends. If c is dropped, "bd" is not a valid pair.
- References: Frits Staal, *The Fidelity of Oral Tradition and the Origins of Science* (1986); the "Vedic chant" literature.

**Saṃyama.** Yoga Sūtra 3.1–3.6:

| Sūtra | Text | Meaning |
| --- | --- | --- |
| 3.1 | *deśabandhaś cittasya dhāraṇā* | binding the mind to one place |
| 3.2 | dhyāna | an unbroken flow of cognition there |
| 3.3 | samādhi | only the object shines forth |
| 3.4 | *trayam ekatra saṃyamaḥ* | the three on one object are saṃyama |
| 3.5 | *tajjayāt prajñālokaḥ* | from its mastery, the light of insight |
| 3.6 | *tasya bhūmiṣu viniyogaḥ* | it is applied in stages |

**The three kinds of knowledge.** Bhagavad Gītā 18.20–22:

| Verse | Kind | Description |
| --- | --- | --- |
| 18.20 | sāttvika | Sees the one imperishable reality in all beings, "undivided in the divided" (*avibhaktaṃ vibhakteṣu*). |
| 18.21 | rājasa | Knows the many beings as separate and of different kinds. |
| 18.22 | tāmasa | Clings to one single effect as if it were the whole (*kṛtsnavad ekasmin kārye saktam*), without reason, narrow. |

## 2. Mappings (mine)

**PATHA.** Before an observed case may revise, support or form lessons, it is recited through overlapping pairs of adjacent features (f1 f2, f2 f3, and so on).
- A pair is *checkable* if at least 3 stored cases share both its values.
- A pair *breaks* if none of those cases carries the case's label.
- If at least 2 pairs are checkable and more than half of them break, the case is held as suspect and set aside. It is not stored, so it neither revises, supports nor forms lessons. A broken word in krama recitation is not passed on.
- *Amended before any code.* The first wording kept suspect cases in memory. That cannot be done cleanly: stored cases also block impure lesson formation, so a stored suspect case would still shape lessons.

**SAMYAMA.** When no lesson decides, the learner works in three steps:
1. **Dhāraṇā:** it binds attention to the case's place, its 30 nearest stored cases (ties go to the most recent).
2. **Dhyāna:** it considers only those cases.
3. **Samādhi:** among them, it forms the shortest conjunction of the case's own values, one value or else two, that holds for at least 3 of them with a single label. The largest support is preferred.

It answers with that conjunction's label; if there is none, it answers with the nearest case. It is applied only after the global lessons fail (3.6, in stages).

**GUNA (the ranking).**

| Kind | Learner | Reading |
| --- | --- | --- |
| Sāttvika | R-ORD | lessons that unify many cases; sattva predominates, with the nearest case subordinate |
| Rājasa | EXT-1NN | each case kept separately |
| Tāmasa | EXT-MAJ | the most frequent label so far, clinging to one effect as the whole |

The Gītā's ranking predicts sāttvika > rājasa > tāmasa.
