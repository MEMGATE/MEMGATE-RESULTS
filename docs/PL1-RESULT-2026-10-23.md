## The lines (no model)
- Memory held the current holder for 180 of the 240 offices.
- 35 offices got a line: 31 named the real new holder, 4 another value, and none an attacker's value. 30 lines rested on two independent sources, 4 on three and 1 on five.

## What it shows
- **The line recovers part of the layer's cost, safely.** Telling the model what two or more independent established sources report, but memory has not verified yet, raised current holders named by 5.21 points over the layer alone, in every model (+4.6 to +5.8). No model named an attacker's value with it.
- **A gap remains.** With the line, the models named the current holder 9.90 points less often than with a memory that believes the latest report, which also passed attackers' values on 5.7–7.1% of attacked offices.
- **Nothing else got worse.** Previous-holder answers held, and both "still in post?" answers improved slightly.

## Limits
- **The attackers are MC-1's simulated ones.** In this world no attacker's value reached two independent established sources, so no line carried one. Colluders that pass as independent would put their value in a line. The line says "not yet verified", and what a model does with it then is not measured here.
- One world; four models; the line informs, it does not decide.
