## What it shows
- **In code, the world can be the registry.** A claimed usage either exists in the release current at the time or it does not. With that check and no registry, no invented function, parameter or package entered memory in any of the 20 worlds. Truth discovery took them in on 8.4–33.1% of facts.
- **The check buys speed.**
  - One established voice is enough once the claim passes the check. ENV k=1 covers 10.6 pp more than RF-1's gate, which has no check and needs three voices.
  - It covers 8.0 pp more than truth discovery's most permissive setting.
- **Together with RF-1:** where the world can check a claim, the gate learns fast and safely. Where it cannot, three independent voices keep attackers out at a slower pace.

## Limits
- **H1 holds largely by construction.** Every false value here is an invention, and inventions fail the check. An attacker that names a real but wrong usage would pass the check; none is in this world.
- **The check is computed from CD-1's recorded release data,** the OLD and NEW API surfaces and the release dates found by installing the releases. No code was run in this experiment.
- **Scope:** API usages of 29 Python libraries, simulated over real 2025–26 release timelines.
