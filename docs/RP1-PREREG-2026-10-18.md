## Rules

- **Verdicts.** Each effect R1–R6 gets the usual verdict.
- **Replication.** An effect *replicates* if its point estimate is positive and its CI lower bound is above 0.
- **Selective effects.** R2 and R6 count 0 for a run with no answered case.
- **INVALID conditions:** any non-determinism in the repeats, or a failed run.
