# PN-2: gaṇa, a rule stated over a listed class of values (Aṣṭādhyāyī 1.1.27 and the gaṇapāṭha)

**Status:** design, written on 18 October 2026 before any PN-2 code. No model calls are made.

## 1. Source and mapping

**Aṣṭādhyāyī 1.1.27**, *sarvādīni sarvanāmāni*: "the words beginning with *sarva* are called *sarvanāman*" (pronominals). Pāṇini names a class by its first member. The class itself is listed in the *gaṇapāṭha*, the list of word-classes that rules cite as "X and the rest" (*X-ādi*). One rule then applies to every listed member at once.

Some classes are *ākṛtigaṇa*, "classes known by their pattern". Their lists are open: a word that behaves like the members belongs, though it is not listed. This is the standard account of the gaṇapāṭha in the Pāṇinian tradition (for example Cardona's survey of Pāṇini). The mapping below uses only these two points.

**Why it is tested now.** PN-1 tested Pāṇini's other class device, the pratyāhāra (a contiguous stretch of an ordered list), and won (+1.19 pp). The gaṇa is the device for classes that are not contiguous: values of a nominal feature that behave alike, named and used together.

**The mapping (mine).**
- **Which features.** A gaṇa is formed for every nominal (unbinned) feature with more than 4 distinct values in the dataset.
- **Membership.** At each case, a value belongs to the gaṇa of the label most frequent among the observed cases carrying that value. Membership needs at least 5 such cases; ties go to the label seen first. This is the ākṛtigaṇa reading: membership comes from behaviour, and new values join when their record qualifies.
- **The gaṇa feature.** For each such feature, one derived feature is appended: the gaṇa of the case's value, or missing if the value does not yet qualify. It is computed before the case's own label is seen.
- **How lessons use it.** A lesson can then name the gaṇa ("the value is one of the X-ādi") instead of a single value.

## 2. Arms

| Arm | Content |
| --- | --- |
| R-ORD | the lesson learner on the plain features |
| **R-ORD+GANA** | the same, with the gaṇa features appended |
| R-ORD+GANA-RANDOM | gaṇa features from a random grouping. Each value is assigned once, at first sight, to one of as many groups as there are classes (`random.Random(seed + 2727)`). A control: pooling without behaviour. |

## 4. Hypotheses and decision rules

The decision rules are as before, stratified by dataset.

| Hypothesis | Comparison (prequential accuracy) |
| --- | --- |
| **H1 (primary)** | R-ORD+GANA − R-ORD |
| H2 | R-ORD+GANA − R-ORD+GANA-RANDOM: does grouping by behaviour matter? |
| Descriptive | per dataset; lessons that use a gaṇa feature |

**INVALID if:**
- any run is non-deterministic or crashes;
- no dataset in the main pool has a gaṇa feature.

## 5. Predictions before any PN-2 code

| Hypothesis | Prediction | Reason |
