## Hypotheses and decision rules (unchanged from the spec)

Verdicts use the state after session 12. Each CI is a bootstrap over the 8 worlds (10,000 resamples, seed 12345).

| Hypothesis | Comparison | Rule |
| --- | --- | --- |
| **H1 (primary)** | Poison: GATED − NAIVE | WIN if it falls by ≥ 1 pp and the CI's upper bound is below 0; otherwise NO WIN |
| H2 | Poison: GATED − MAJORITY | the same rule |
| H3 | Current: GATED − NAIVE | NON-INFERIOR if the CI's lower bound is above −5 pp |
| H4 | Locality: GATED − NAIVE | WIN if ≥ +1 pp and the CI's lower bound is above 0; NO WIN if the CI's upper bound is below +1; else UNDETERMINED |
| H5 | Retention: GATED − NAIVE | the same rule as H4 |

**INVALID if:**
- any task fails;
- FROZEN current is above 10%;
- NAIVE current is below 30%.

**Descriptive:**
- stale; the held-out phrasing; current and stale against MAJORITY; static kept;
- poison by kind (stealthy or colluding; changed or static);
- the curve after sessions 4, 8 and 12;
- the training streams, queries, dismissals, rollbacks and routing misroutes;
- the repeat;
- after the main run, the gate audit without a learner on the main seeds.
