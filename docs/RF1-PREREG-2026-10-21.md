**Status:** frozen 21 October 2026, before any main world was generated. Spec and preregistration are one document; the exploration behind it is in LOG (21 October) and `cl/rf1_explore.py`.
**Dev run:** `runs/rf1-dev-20261021.jsonl` (worlds 8490–8492, OB-1's dev worlds).

## 1. Question
Every gate so far earns trust in a source from a registry: an authority that confirms some claims.
- With no registry, gates v1–v3 learn nothing.
- Truth discovery and majority vote let attacker values in (OB-1).

Can a gate with **no registry at all** keep attacker values out and still learn the changes?

## 2. Design
**Worlds:** AU-2's worlds. Each holds TM-1's 1,341 real offices, TM-1's sources and attackers, and AU-1's three adaptive attacker groups. The registry is removed from both channels, unasked reports and questions (OB-1's share q = 0).
- Dev: worlds 8490–8492.
- **Main: worlds 8700–8719**, never generated before this freeze.

**The registry-free gate** (`cl/rf1_gate.py`, frozen settings):
- **Established sources only.** A source is heard once it has claims in at least 2 sessions and at least 20 claims. Fresh accounts are not heard.
- **One voice for sources that dissent together.** Two sources count as one voice if their latest claims agree on a value memory never settled, while memory settled another, at least 5 times and on at least 5% of the values they share. Each such claim must be 2 or more sessions old.
- **Settling a value:**
  - a value enters memory when at least **3** independent voices hold it;
  - a value the fact never held before also needs claims in at least 2 sessions;
  - between two such values, the one claimed more recently wins.
- **Staleness.** A source stops counting after 3 or more staleness strikes, if they are also at least 10% of its judged claims. A strike is naming a value the fact held before, 2 or more sessions after memory settled a newer one.
- **Nothing is dismissed.** Memory is recomputed every session from the current claims.

**Arms, all without a registry:**
- NAIVE;
- MAJORITY-1;
- TD-0.5 and TD-0.98 (AU-2's truth discovery);
- **RF** (the gate above);
- RF PERSIST-1, a sensitivity variant that drops the two-session rule, descriptive only;
- GATE-v3 FULL REGISTRY: the same worlds with the registry kept, for scale. Descriptive only.

**Measures, per world and arm** (OB-1's):
- the share of offices where memory ever held an attacker's value;
- coverage of changed offices, as the mean over the 12 sessions and at the end;
- for RF, the honest sources (A, B, C, E) dismissed, unheard at the end, or merged into one voice with any other source.

## 3. Hypotheses and decision rules
Paired over the 20 worlds; 95% interval from 10,000 bootstrap resamples of worlds, seed 12345.

| Test | Comparison | Rule |
| --- | --- | --- |
| **H1 (primary)** | attacker values ever held: RF − TD-0.98 | **WIN** if the interval lies wholly below −1 pp; **NO WIN** if its lower bound is above −1 pp; otherwise UNDETERMINED |
| H2 | mean coverage: RF − TD-0.5 | **WIN** if the interval lies wholly above +1 pp; **NO WIN** if its upper bound is below +1 pp; otherwise UNDETERMINED |
| H3 | coverage at the end: RF − TD-0.5 | as H2 |

TD-0.98 is truth discovery's strictest setting, which lets in the fewest attacker values. TD-0.5 is its most permissive, which covers the most. RF has to beat the first on attacker values and the second on coverage.

**Guard, reported for every world:** honest sources dismissed, unheard at the end, or merged. Any count above 0 is reported beside the verdicts.

## 5. Limits, stated before the run
- **Attackers.** They are TM-1's and AU-1's. None controls three or more established sources that name the same false value. The three budget exhausters name past holders, not lies.
  - The rule of 3 independent voices is exactly what such a group would have to beat.
  - Attackers built against this gate are not tested here.
- **Honest sources.** They lag by one session and never lie. Real sources also make honest errors.
- **Facts.** Office holders only, in simulation over real timelines.
- **Coverage.** It rises slowly in the first sessions, because sources must first be established.
