## What RV-2 cannot show
- **The registry here is Wikidata's own settled timeline.** It is the hindsight consensus of the same editors, standing in for an official source. RV-2 tests how the gate treats real editors' timing, mistakes and records, not whether a registry is right. AU-2 tested a registry wrong 5–10% of the time.
- **Edits that never name an office property in their summary are not in the stream:** qualifier-only API edits, bulk edits and reverts. Their effect is still seen, because each edit is read against its own parent revision.
