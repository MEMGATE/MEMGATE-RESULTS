## What this means

**SE-2 attacked the gate where SE-1 was weakest, and the new gate held.**
- **The attacks:**
  - a poisoner lied only about *dark* facts, which the registry never reports;
  - two colluders asserted the same false values together, satisfying the rule that two sources must agree.
- **What SE-1's gate did:** it was fooled. It trained the model on about 70 poisoned reports per world and left 8.8% of the poisoned facts answered falsely, 14% of the colluded ones.
- **What SE-2's gate did:** nothing poisoned ever reached the weights, in any world or session.

**What made the difference is jijñāsā, asking under doubt.**
- **When it asks:** only when trusted sources disagree about a fact.
- **What it does:** it queries the registry about that one fact, within a budget, and counts the answer against every source that claimed otherwise.
- **The result:** the colluders were caught and dismissed within the first two sessions. It used about 35 queries per world, a third of the budget.
- **A simple majority vote is not enough.** It needs no queries, but still trained on 18–42 poisoned reports per world, because colluders outnumber the honest reports of a fact early on.

**Smṛti is not viparyaya, and the distinction was needed** (Yoga Sūtra 1.6–1.11).
- **The problem:** honest sources report a changed fact's old value for a session. Counted as error, that lag got an honest source dismissed in 2 of 4 dev worlds before the rule was added.
- **The rule:** a value the gate once held is a memory of a past state, not a lie.
- **The effect:** it excused 39–65 lagging claims per world, and no honest source was dismissed.

**Safety cost no learning; it added learning.**
- **Truth:** GATED-SE2 learned more of the facts than NAIVE (98.3% against 91.6%), by trained and new phrasing alike.
- **Retention:** it kept more core ability (99.6% against 95.4%).
- **Why:** removing contradictions makes the stream easier to learn, as in SE-1.

**The cost is a short delay on changes nobody verifies.**
- **The measure:** on changed facts the gate is level with NAIVE (H5: −0.99, UNDETERMINED).
- **Older values:** GATED-SE2 still gave an older value for 1.7% of the changed facts, against 0.6% for NAIVE.
- **Why:** a change to a dark fact is admitted only once two trusted sources report it, or a dispute triggers a query.
- **SE-1's gate was much worse here** (78.7% latest, 9.2% older): it lets a stale value with two supporters win.

## Limits, stated plainly

- **The world is synthetic.** It has invented companies, a scripted poisoner and scripted honest lag. Real facts the model already believes are untested (SE-3).
- **The registry is an oracle.** Queries return the truth. A real registry can be wrong or slow, and a query has a cost this test only counts.
- **The model is still small (1.5B), and it learned facts, not skills.**
- **Several things were measured on the same worlds.** The 8 worlds are independent draws, but each arm saw the same 8, so arms are compared within worlds.
