## Rules fixed in the code

**PATHA.**
- A pair of adjacent features is checkable with at least 3 stored matches.
- It breaks when none of those matches carries the label.
- A case is set aside, and not stored, when at least 2 pairs are checkable and more than half of them break.

**SAMYAMA.**
- It works over the 30 nearest stored cases (ties go to the most recent).
- It looks for the shortest pure conjunction of the case's own values, one value or else two, holding for at least 3 of those cases. The largest support wins, then the earliest in sorted order.
- Otherwise the nearest case answers.

**EXT-MAJ.** It predicts the most frequent label so far; ties go to the label seen first.

**The ranking holds** if R-ORD − EXT-1NN and EXT-1NN − EXT-MAJ are both positive, with CI lower bounds above 0.

**INVALID conditions:**
- any non-determinism in the repeats;
- a failed run;
- PATHA never setting a case aside on the held-out data;
- SAMYAMA never attempting on the held-out data.

## Dev run (exposed data)

The output is in [`runs/sr8-dev-20261018-a`](../runs/sr8-dev-20261018-a/SUMMARY.md). It covers the 18 held-out datasets of PV-1 and MX-2, in orders 2000–2009, and the synthetic dev seeds. There were 3,240 runs, all 184 repeats were identical, and nothing failed.

| Comparison (exposed data) | pp, 95% CI |
| --- | --- |
| H1: R-ORD+SAMYAMA − R-ORD | −0.03 [−0.13, +0.08] |
| H2: R-ORD+PATHA − R-ORD | **−7.68 [−8.19, −7.20]** |
| H3: MIX-SR8 − R-ORD | −7.72 [−8.23, −7.24] |
| H4: R-ORD − EXT-1NN | +0.81 [+0.67, +0.94] |
| H4: EXT-1NN − EXT-MAJ | +22.81 [+22.59, +23.03] |
| R-ORD+SAMYAMA − R-ORD+KNN7 | −0.66 [−0.79, −0.53] |

On synthetic NOISE, SAMYAMA gave +2.51 pp.

**Findings.**
- **PATHA, the krama check, fails badly on data with many classes.**
  - On semeion (10 classes) it set aside 73% of the cases and lost 46.0 pp. Mice lost 27.4, texture 26.9 and vowel 21.7.
  - When many classes share each pattern of two adjacent values, a genuine case of a class not yet seen with that pattern looks like a corruption.
  - On imbalanced two-class data it helped a little: jm1 +2.0, kc2 +1.2, pc3 +1.1, Amazon +1.0.
  - The check suits a fixed text that must not change. In data, a new combination is often true.
- **SAMYAMA, the local lesson, is ≈ 0 overall.**
  - It helps on two-class data: elevators +2.3, jm1 +2.0, pc3 +1.6.
  - It hurts with many classes: mice −3.9, semeion −2.7, vowel −2.6.
  - It is below the plain seven-neighbour vote (−0.66).
- **The Gītā's ranking holds on average, but not dataset by dataset.**
  - The majority guess, tāmasa, beats both other learners on very imbalanced sets: Amazon, click, jm1 and pc3.
  - The nearest case, rājasa, beats the lessons on mice, semeion, texture and vowel.

PATHA was not changed after the dev run. Its failure is the faithful reading's result, not a bug, and it is preregistered as found. No other change was made.
