# MEMGATE-RESULTS — Dedicated GPU Runs & Evaluation Reports (MEMGATE)

Yeh private repository **saare GPU Runs, Preregistered Tests, aur Evaluation Reports (`*report*.json`)** ke liye hai.
(Saare secrets aur encrypted vault `MEMGATE/SHAKTI` mein alag surakshit hain.)

---

## Folders
1. **`RUNS-LATEST.md`:** Har GPU run ka live status (`Started`, `Packed`, `Done`).
2. **`runs/`:** Saare 150+ GPU runs ke `manifest.json`, `gcp.json`, aur final evaluation reports (`report-*.json`, `bl3-report.json`, `su1-report.json`, etc.).
3. **`journal/`:** Har din ka step-by-step GPU orchestrator record (`2026-10-28.md` se `2026-11-01.md`).
4. **`docs/`:** Saare preregistrations (`*-PREREG-*.md`), results (`*-RESULT-*.md`), aur plans.
